# Research Brain

논문, 세미나 노트, 내 생각, 내 연구 프로젝트를 한곳에서 관리하는 개인용 연구 노트 웹앱입니다. 노션에서 옮겨 오는 것을 전제로 조용한 디자인과 PDF 이어 읽기를 핵심으로 합니다. 혼자 쓰는 앱이며 내 컴퓨터에서 실행합니다.

## 요구사항

- Node.js 24
- npm (이 프로젝트는 `package-lock.json`으로 의존성을 고정합니다)

## 설치

```bash
npm ci
```

## 환경 설정

설정 파일은 `.env.example`을 복사해서 만듭니다. 값은 직접 입력하며, `.env`는 절대 커밋하지 않습니다 (`.gitignore`에 포함되어 있습니다).

```bash
cp .env.example .env
```

- **로컬 모드 (기본):** `DATABASE_URL`을 비워 두면 `file:./data/local.db` 로컬 SQLite 파일을 사용합니다. 별도 설정이 필요 없습니다.
- **Turso 모드:** `DATABASE_URL`에 Turso 데이터베이스 주소, `DATABASE_AUTH_TOKEN`에 토큰을 넣으면 Turso를 사용합니다. 두 값을 모두 채워야 합니다.

## 데이터베이스 준비

```bash
npm run db:migrate
```

`drizzle/` 폴더의 마이그레이션 SQL을 현재 DB에 적용합니다. 새로 설치했거나 DB 구조가 바뀐 뒤에 실행합니다.

### 샘플 데이터 (선택)

```bash
npm run db:seed
```

연구, 논문, 세미나, 생각, 태그, 연결 등 샘플 데이터를 넣고 `data/pdfs/`에 더미 PDF를 만듭니다. 실행하면 **기존 샘플 데이터는 지우고 다시 넣습니다.** 실제 데이터가 있는 DB에서는 먼저 [데이터 백업](#데이터-백업)을 하세요.

> **주의:** seed는 쓰기 작업을 직렬화하기 위해 프로세스 단위로 동작합니다. 개발 서버(`npm run dev`)를 끈 상태에서 실행하세요.

## 실행

```bash
npm run dev
```

브라우저에서 <http://127.0.0.1:3000>을 엽니다. 개발 서버는 로컬 주소(`127.0.0.1`)에만 연결되며 같은 네트워크의 다른 기기에서는 접근할 수 없습니다.

## PDF 저장 위치

업로드한 논문 PDF는 `data/pdfs/<논문 id>.pdf` 경로에 로컬로 저장합니다. 클라우드로 업로드하지 않으며, 파일 이름은 사용자가 정한 이름이 아니라 논문 id로 정해집니다.

## 스크립트

| 명령 | 설명 |

| `npm run dev` | 개발 서버 실행 (`http://127.0.0.1:3000`) |
| `npm run build` | 프로덕션 빌드 |
| `npm run start` | 빌드 결과를 로컬 주소에서 실행 (`build` 후 사용) |

| `npm run db:migrate` | 마이그레이션 적용 |
| `npm run db:seed` | 샘플 데이터 다시 넣기 (개발 서버를 끈 뒤 실행) |

## 단축키

| 키 | 동작 |
| --- | --- |
| `N` | 현재 섹션에 새 항목 만들기 |
| `/` | 홈의 빠른 입력창으로 포커스 이동 (엔터 → 생각으로 저장) |

`Cmd+K` 검색은 2단계에서 추가됩니다.

## 단계별 범위

### 1단계 MVP (현재 구현 범위)

- 데이터 모델: 연구, 논문, 세미나, 생각 4개 타입과 하이라이트 테이블(스키마만)
- 4개 타입 CRUD, 항목끼리 다대다 연결, 태그
- 타입별 양식 (논문, 세미나, 연구)
- 홈 대시보드: 빠른 입력, 이어 읽기, 연구 단계별 칸반, 최근 생각, 최근 세미나
- PDF 뷰어 + 이어 읽기: 스크롤 위치 자동 저장, 다시 열면 마지막 위치로 이동
- 샘플 seed 데이터

### 2단계 (예정)

- 하이라이트와 메모 (PDF 텍스트 선택)
- 전체 검색 (`Cmd+K`): 제목, 본문, 하이라이트
- DOI·arXiv 링크로 논문 정보 자동 채우기 (Crossref, arXiv 공개 API)
- 라이너 스콜라 메모 (붙여넣기 저장, 라이너 바로 열기)
- 백링크, 태그별 모아보기

### 3단계 (예정)

- 연결 관계 그래프 뷰
- 데이터 내보내기 (JSON, Markdown)
- 백업

## 데이터 백업

모든 로컬 데이터는 `data/` 폴더에 있습니다 (`local.db`, `pdfs/`). 백업하려면:

1. 개발 서버를 끕니다 (`Ctrl+C`).
2. `data/` 폴더 전체를 다른 위치에 복사합니다.

DB를 쓰는 중에 복사하면 일부만 담길 수 있으므로 서버를 끈 뒤에 복사하세요. Turso 모드에서는 데이터가 원격 DB에 있으므로 이 방법으로는 백업되지 않습니다.
