# 계획: 그래프 "우주 보기" 모드 (단계 C)

> **승인됨 (2026-11-03)**: 결정 C1~C4 모두 권장안. 순서는 단계 G 병합 → PARA 보완 2가지 → 우주 보기.
> 근거: `docs/PLAN-GRAPH.md`, `docs/design/graph.md`(기본 그래프 시각 규칙), `src/lib/graph/**`, `src/components/graph/**`.

## 0. 목적

Obsidian 그래프처럼 "내 데이터가 우주처럼 어떻게 연결돼 있고 무엇이 중요한지"를 한눈에 보이게 한다.
기본 그래프(조용한 무채색, `docs/design/graph.md`)는 그대로 두고, `/graph` 상단 토글로 전환하는 **별도 모드**다.

## 1. 결정

| # | 결정 |
|---|---|
| C1 | **2D.** 지금의 `react-force-graph-2d` 캔버스 위에 모드를 추가한다. 3D는 하지 않는다. |
| C2 | **중요도 점수(0~1)** = 직접 값 + 연결 중심성 + 최근 활동 + 수동 "중요" 별표. 노드 크기와 밝기에 반영. |
| C3 | **영역별 은하 색.** 영역마다 색 하나, 같은 영역 항목이 한 은하처럼 모이도록 클러스터 힘. 영역 없는 항목은 중립색. 인생 목표는 중심의 태양처럼. |
| C4 | 시간 흐름 슬라이더는 **이번에 하지 않는다.** |

## 2. 화면

- **배경**: 어두운 우주 바탕(이 모드에서는 라이트 테마여도 어둡게) + 배경 별.
- **노드**: 은은한 발광(glow). 모양은 기본 그래프와 같게 유지(색만으로 구분하지 않음).
- **움직임**: 아주 느린 흐름 애니메이션. `prefers-reduced-motion`이면 정지.
- **"왜 중요한가"**: 노드를 클릭하면 그 항목 → 프로젝트 → 분기·연 목표 → 인생 목표 경로를 별자리처럼 선으로 강조.
- **옆 패널**
  - 중요도 Top 10
  - 연결 없는 외톨이 별(정리 대상)
  - 오래 손대지 않은 중요한 항목

## 3. 중요도 점수 (C2)

| 요소 | 내용 |
|---|---|
| 직접 값 | 논문 중요도(핵심 > 참고 > 가볍게), 목표 단계(인생 > 연 > 분기), 프로젝트 상태(진행 중, 마감 임박 가산) |
| 연결 중심성 | degree 또는 PageRank(정규화) |
| 최근 활동 | 마지막 읽음·수정 시각에서 지수 감쇠 |
| 수동 가중 | 항목마다 "중요" 별표 |

- 가중치와 정규화는 구현자·디자이너가 정하고 문서(`docs/design/cosmos.md`)에 값으로 남긴다. 점수 계산은 순수 함수 + 단위 테스트.
- **별표 저장**: 스키마 변경이 필요하면 다음 마이그레이션 번호(`0003`)로 ADD COLUMN만. 루트 DB에는 적용하지 않고 보고에 "마이그레이션 필요"로 적는다.

## 4. 접근성

- 색만으로 구분하지 않는다(모양 유지).
- 키보드 탐색(기존 화살표·`[` `]`·Enter·Esc)을 유지한다.
- 대비 기준(노드 3:1, 글자 4.5:1)을 유지한다. 어두운 배경에서도 지킨다.

## 5. 팀과 순서

- 팀: 구현자 1명(그래프 담당) + 디자이너 1명 + 리뷰어 1명.
- 순서: ① 디자이너 시각 규칙 `docs/design/cosmos.md`(색 팔레트·발광·배경 별·애니메이션 속도·패널) ② 구현자: 점수 계산·데이터(필요하면 별표 스키마) → 우주 모드 캔버스·클러스터 힘·별자리 경로·옆 패널 ③ 리뷰 → 병합 → 점검(lint·타입·단위·빌드·e2e) → 보고 후 멈춤.
- 화면 확인은 headless로만. push 금지.
