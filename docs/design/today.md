# 할 일·오늘 화면·빠른 캡처 시각 규칙 (단계 T)

> 근거: `docs/PLAN-TODAY.md`(승인), `docs/SPEC.md` 디자인 가이드, `src/app/globals.css` 토큰, 기존 부품 `src/components/{ui,fields,list,dashboard}`, `docs/design/graph.md`.
> 대상: 구현자 A(할 일 목록·`/tasks`), 구현자 B(홈·회고 초안·그래프 노드·빠른 캡처). 값은 그대로 옮겨 쓰면 되도록 클래스·숫자로 적었다.
> 원칙: **조용하게.** 새 색·새 CSS 변수 없음. 기존 토큰(`text-fg/muted`, `border-border`, `tone-*`)과 기존 부품(`Button`, `Badge`, `Kbd`, `EmptyState`, `Dialog`, `LinkTabs`, `DashboardSection`, `controlClass`)만 쓴다. 숫자는 모두 `tabular-nums`. 보조 글자에 `text-faint`(라이트 2.6:1)는 쓰지 않는다.

## 0. 대비 기준 (계산값)

| 쓰임 | 토큰 | 라이트 (`#fff` 위) | 다크 (`#141416` 위) |
|---|---|---|---|
| 본문 | `text-fg` | 17.9 | 15.9 |
| 보조 글자, 마감일 기본, 내일 | `text-muted` | 5.3 | 6.8 |
| 마감 **오늘** | `text-tone-amber-fg` | 5.9 | 9.3 |
| 마감 **지남** | `text-tone-red-fg` | 6.9 | 8.3 |
| hover 행(`bg-hover`) 위 `text-muted` | — | 4.6 | 5.6 |

- 글자는 모두 4.5:1 이상. 포커스 링은 전역 `:focus-visible`(accent 2px, offset 2px) 그대로.
- 마감 상태는 **색 + 글자**로 함께 표시한다(색만으로 구분하지 않음, WCAG 1.4.1).

## 1. 마감일 표기 (공통 함수 1개)

`formatDue(dueDate, today) → { text, tone }` 하나를 만들어 할 일 목록·`/tasks`·홈이 같이 쓴다. 날짜 규칙은 앱 공통(`src/components/ui/format.ts`, 달력 날짜는 절대값 `YYYY.MM.DD`)을 따르되, 가까운 이틀만 말로 쓴다.

| 조건 | 글자 | 색 (`tone`) | 굵기 |
|---|---|---|---|
| 완료된 할 일 | `formatDate(dueDate)` | `text-muted` | 400 |
| `due < today` | `지남 · 2026.11.01` | `text-tone-red-fg` | 500 |
| `due = today` | `오늘` | `text-tone-amber-fg` | 500 |
| `due = today + 1` | `내일` | `text-muted` | 400 |
| 그 밖 | `2026.11.07` | `text-muted` | 400 |
| 없음 | (표시 안 함; 편집 시 "마감일" 자리표시) | — | — |

- 크기 `text-xs tabular-nums whitespace-nowrap`. 배지(배경색)는 쓰지 않는다 — 글자색만 은은하게.
- 지남은 며칠 지났는지가 아니라 원래 날짜를 보인다(오늘이 바뀌어도 읽히는 값). 스크린 리더용 `title`/`aria-label`은 "마감 지남, 2026년 11월 1일"처럼 풀어 쓴다.
- 날짜 기준 `today`는 서버에서 로컬 날짜(`YYYY-MM-DD`)로 한 번 정해 내려준다(클라이언트·서버 자정 어긋남 방지).

## 2. 할 일 목록 (`src/components/tasks/TaskList`)

프로젝트·목표·영역 상세의 "할 일" 섹션, `/tasks`, 홈이 같은 행 부품을 쓴다. 상세 화면 섹션 머리는 기존 상세 섹션 제목 스타일을 그대로 쓰고 옆에 `text-xs text-muted tabular-nums` "3/8"(완료/전체).

### 2.1 구조

```
할 일  3/8
┌──────────────────────────────────────────────────────────────┐
│ ⋮⋮ ☐  자료 조사 마무리                          오늘     ⋯ │  h-9
│ ⋮⋮ ☐  지도교수 미팅 준비                        내일     ⋯ │
│ ⋮⋮ ☐  2장 초안                                  2026.11.20 ⋯ │
│     ＋ 할 일 추가                                              │  입력 줄
└──────────────────────────────────────────────────────────────┘
▸ 완료 3
```

- 목록: `<ul aria-label="할 일">` + `flex flex-col`. 바깥 테두리·카드 없음(상세 본문에 그대로 놓임). 행 사이 구분선 없음 — 행 높이와 hover 배경으로만 구분.
- 행: `<li class="group flex h-9 items-center gap-2 rounded-md px-1.5 hover:bg-hover focus-within:bg-hover">`.
  1. **핸들** (2.4) — 폭 20px.
  2. **체크박스** — 네이티브 `<input type="checkbox">` 16×16(`size-4`), 전역 `accent-color`. 클릭 영역은 `<label>`로 24×24 확보(`grid size-6 place-items-center`). `aria-label="완료: {제목}"`.
  3. **제목** — `flex-1 min-w-0 truncate text-sm text-fg`. 클릭하면 그 자리에서 편집(2.3).
  4. **소속** (`/tasks`·홈에서만) — `text-xs text-muted truncate max-w-40`, 앞에 종류 글자 "프로젝트 · " 없이 제목만, `hover:text-fg` 링크. 소속 없음이면 생략.
  5. **마감일** — 1절 표기. 마감이 없으면 hover/포커스 때만 `text-xs text-muted` "마감일" 버튼이 보인다.
  6. **더 보기** — `ghost icon` 28×28, `aria-label="할 일 메뉴: {제목}"`, 평소 `opacity-0 group-hover:opacity-100 group-focus-within:opacity-100`(키보드로는 항상 도달 가능). 메뉴: 마감일 정하기 / 마감일 지우기 / 삭제.
- 완료된 행: 제목 `text-muted line-through decoration-border-strong`, 체크 표시. 완료 직후 그 자리에 **600ms** 머문 뒤 "완료" 묶음으로 옮긴다(실수 되돌릴 틈). reduced motion이어도 지연은 유지, 이동 애니메이션만 없음.
- 마감일 편집: 기존 `DateField`(네이티브 date input)를 행 안 작은 팝오버(`rounded-lg border border-border bg-bg shadow-overlay p-3`)로 띄운다. 빠른 선택 `ghost sm` 3개: "오늘" "내일" "다음 주 월요일", 아래 "지우기".

### 2.2 추가 입력 줄

- 목록 맨 아래 같은 행 높이(`h-9`), 왼쪽 정렬을 체크박스 열에 맞춘다(`pl-[30px]`).
- 평소: `ghost` 버튼처럼 보이는 `text-sm text-muted` "＋ 할 일 추가". 누르면 그 자리가 입력창(`controlClass` 대신 테두리 없는 `h-9 bg-transparent text-sm`, 아래 `border-b border-border-strong`)으로 바뀐다.
- `Enter` 저장 후 **입력창 유지·비움**(연달아 입력). IME 조합 중 Enter 무시(`QuickInput`과 같은 `isComposing || keyCode 229` 검사). `Esc` 또는 빈 상태로 blur → 원래 버튼으로.
- 입력 안 날짜 줄임말은 **이번 단계에서 하지 않는다**(조용하게, 예측 가능하게). 마감일은 저장 뒤 행에서 정한다.
- 300자 초과: 입력창 아래 `text-xs text-danger` "300자까지 쓸 수 있습니다." (`aria-describedby`).
- 저장 실패: 입력값을 지우지 않고 같은 자리에 `text-xs text-danger` 오류 문구.

### 2.3 제목 편집

- 제목 클릭 또는 행 포커스에서 `F2`/`Enter`(체크박스·버튼이 아닌 제목 버튼에 포커스일 때) → 같은 글자 크기의 입력창으로 바꿈. `Enter`·blur 저장, `Esc` 취소. 빈 제목으로 저장하면 취소로 본다(삭제 아님).

### 2.4 순서 바꾸기

- 핸들: `<button class="grid h-6 w-5 cursor-grab place-items-center rounded text-muted opacity-0 group-hover:opacity-100 focus-visible:opacity-100">` + 6점 그립 아이콘 12px. `aria-label="순서 바꾸기: {제목}"`, `aria-describedby`로 숨김 도움말 "위아래 화살표로 옮깁니다."
- **키보드**: 핸들에 포커스한 채 `↑`/`↓` → 한 칸 이동, 포커스는 옮겨진 핸들을 따라감. 행 어디서든(제목 편집 입력 포함) `Alt+↑`/`Alt+↓`도 같은 동작.
- 마우스: 핸들 끌어 놓기. 끄는 동안 행 `bg-bg shadow-overlay rounded-md`, 놓일 자리에 `h-0.5 bg-accent` 줄. 끌기를 구현하기 어렵다면 키보드·메뉴("위로"/"아래로")만으로도 기준 충족.
- 알림: `aria-live="polite"` 영역에 "{제목}, 8개 중 2번째로 옮김".
- 순서는 **같은 부모 안에서만**. `/tasks`의 "오늘·이번 주·마감 지남" 탭과 홈은 마감일 순이라 핸들을 **표시하지 않는다**(소속별 탭에서만 보임).
- 완료된 할 일은 순서 바꾸기 없음.

### 2.5 키보드 요약

| 위치 | 키 | 동작 |
|---|---|---|
| 목록 | `Tab` | 행마다 핸들 → 체크박스 → 제목 → (마감일) → 더 보기 순 |
| 체크박스 | `Space` | 완료 토글 |
| 제목 | `Enter` / `F2` | 편집 |
| 핸들 | `↑` `↓` | 순서 이동 |
| 행 어디서든 | `Alt+↑` `Alt+↓` | 순서 이동 |
| 편집 중 | `Enter` 저장 · `Esc` 취소 | |
| 추가 줄 | `Enter` 저장 후 계속 · `Esc` 닫기 | |
| 더 보기 메뉴 | `↑↓` 이동 · `Enter` 실행 · `Esc` 닫고 버튼으로 포커스 복귀 | |

- 행의 단일 글자 단축키는 만들지 않는다(전역 `N`·`G`·`C`·`/`와 겹치지 않게).
- 삭제는 확인 대화상자 없이 바로 하고, 목록 아래 `text-[13px] text-muted` 한 줄 "‘{제목}’을 지웠습니다. **되돌리기**"를 5초 보인다(`aria-live="polite"`, 되돌리기는 `underline` 버튼). 되돌리기를 만들기 어렵다면 기존 `DeleteItemButton`과 같은 확인 `Dialog`로 대신한다.

### 2.6 완료 접기

- 미완료 목록 아래 `<button aria-expanded aria-controls>`: 셰브런 12px(▸/▾) + `text-[13px] text-muted` "완료 3"(숫자 `tabular-nums`). 기본 **접힘**.
- 펼치면 완료된 할 일을 완료 시각 최신순, 최대 20개 + "완료 23개 중 20개 표시" `text-xs text-muted`.
- 완료 0개면 버튼 자체를 숨긴다.
- 접힘 상태는 저장하지 않는다(화면마다 항상 접힘으로 시작).

### 2.7 빈 상태

`EmptyState`는 크고 무거우므로 상세 섹션에서는 쓰지 않는다. 추가 줄 위에 한 줄:

| 위치 | 문구 (`text-[13px] text-muted`) |
|---|---|
| 프로젝트 상세 | 아직 할 일이 없습니다. 다음에 할 일을 하나 적어 보세요. |
| 목표 상세 | 아직 할 일이 없습니다. 연결된 프로젝트가 없다면 할 일로 진행률을 셉니다. |
| 영역 상세 | 아직 할 일이 없습니다. |
| 모두 완료 (미완료 0, 완료 ≥ 1) | 남은 할 일이 없습니다. |

## 3. `/tasks` 페이지

- 사이드바 "할 일": `NAV_SECTIONS.top`에서 **수집함 다음, 회고 앞**(홈 → 수집함 → 할 일 → 회고). 아이콘은 기존 `icons.tsx` 선 굵기·크기에 맞춘 체크 상자(둥근 사각 + 체크).
- `<Page>` + `PageHeader` 제목 "할 일", 설명 없음. 오른쪽 액션 없음(추가는 탭 안의 추가 줄).

### 3.1 탭

`LinkTabs`(URL 탭, `?tab=`) 그대로. 각 탭 옆 개수(`count`, 미완료만).

| 값 | 라벨 | 내용 | 정렬 | 추가 줄 |
|---|---|---|---|---|
| `today` (기본) | 오늘 | 마감 지남 + 오늘 마감, 미완료 | 지남 먼저, 그 안에서 마감일 → 부모 순서 | 있음 — 새 할 일 마감 = 오늘, 소속 없음 |
| `week` | 이번 주 | 이번 주(월~일, ISO 주) 마감, 미완료. 지난 날짜는 "마감 지남" 탭으로 | 마감일 | 없음 |
| `overdue` | 마감 지남 | `due < today`, 미완료 | 마감일 오래된 순 | 없음 |
| `by-parent` | 소속별 | 모든 미완료 | 그룹(3.2) 안에서 부모의 순서 | 그룹마다 있음 |

- "마감 지남" 탭 개수가 1 이상이면 숫자만 `text-tone-red-fg`(탭 라벨은 그대로 muted/fg).
- 탭과 목록 사이 `mt-6`.

### 3.2 그룹 레이아웃 (오늘·이번 주 탭)

날짜 그룹. 그룹 머리 `h-8 flex items-baseline gap-2`: 날짜 `text-[13px] font-semibold text-muted` + 개수 `text-xs text-muted tabular-nums`. 그룹 사이 `gap-6`.

- 오늘 탭: "마감 지남" / "오늘" 두 그룹(빈 그룹은 숨김).
- 이번 주 탭: 요일별 "11.04 수" … 형식, 오늘 그룹은 "오늘", 내일은 "내일". 마감 없는 날은 그룹 없음.
- 각 행에 소속 링크(2.1-4)를 보인다. 마감일 글자는 그룹이 이미 날짜를 말하므로 **지남 탭·지남 그룹에서만** 보이고 나머지는 숨긴다.

### 3.3 그룹 레이아웃 (소속별 탭)

```
프로젝트
  논문 A 작성                              2/5  →
    ☐ …
목표
  2026-Q4 학위 논문 1장                    0/2  →
영역
  연구실                                    1/1  →
소속 없음                                         3
```

- 큰 묶음 순서: **프로젝트 → 목표 → 영역 → 소속 없음**. 큰 묶음 제목 `text-[13px] font-semibold text-muted`, 묶음 사이 `gap-8`.
- 부모 머리 `h-9 flex items-center gap-2`: 부모 제목 링크 `text-sm font-medium text-fg hover:underline` + `text-xs text-muted tabular-nums` "2/5" + 오른쪽 `→`(sr-only "열기"). 아래 그 부모의 `TaskList`(핸들·추가 줄 포함), 왼쪽 들여쓰기 없음.
- 부모 정렬: 프로젝트는 마감일 → 제목, 목표는 기간(인생 → 연 → 분기), 영역은 `sort_order`. 미완료 할 일이 없는 부모는 숨김.
- 보관된 부모의 할 일은 보이지 않는다(PLAN 1절).
- "소속 없음" 그룹 = 할 일 수집함. 추가 줄 기본 소속이 여기.

## 4. 오늘 화면 (홈 `/`)

기존 홈의 리듬(섹션 사이 `gap-10`, `DashboardSection` 제목 `text-[13px] font-semibold text-muted`)을 그대로 쓴다. **새 섹션은 모두 비면 숨긴다**(빈 문구로 화면을 채우지 않음) — 단 "오늘" 섹션만 예외(4.2).

### 4.1 섹션 순서

| # | 섹션 | 내용 | 최대 | 비었을 때 |
|---|---|---|---|---|

### 4.2 "오늘" 섹션 세부

- 제목 "오늘" 옆에 개수 `text-xs text-muted tabular-nums`. 지남이 있으면 "오늘 3 · 지남 2"처럼 지남 숫자만 `text-tone-red-fg`.
- 지남 할 일은 맨 위, 마감일 글자 `지남 · 2026.11.01`. 오늘 할 일은 마감일 글자를 숨긴다(섹션이 이미 오늘).
- 모두 완료하면 "오늘 할 일을 모두 끝냈습니다." `text-[13px] text-muted`(축하 애니메이션·이모지 없음).

### 4.3 분기 목표 행

- 행 `flex flex-col gap-1.5 py-1.5`: 제목 링크 `text-sm text-fg truncate` + 오른쪽 `text-xs text-muted tabular-nums` "40%".
- 진행 막대: 높이 4px `rounded-full bg-subtle`, 채움 `bg-accent`(이어 읽기 진행 막대와 같은 모양이면 그 부품 재사용). `role="progressbar" aria-valuenow aria-valuemin=0 aria-valuemax=100 aria-label="{제목} 진행률"`.
- 진행률 근거가 할 일이면(PLAN 2절) 막대 아래 `text-xs text-muted` "할 일 2/5", 프로젝트면 "프로젝트 1/3". 수동이면 생략.

### 4.4 다시 볼 별 행

- `h-9 flex items-center gap-2`: 종류 `Badge`(기존 `ITEM_TYPE` 톤) + 제목 링크 `text-sm truncate` + 오른쪽 `text-xs text-muted tabular-nums` "21일 전"(`formatRelative`는 7일 넘으면 날짜가 되므로 여기서는 "n일 전"으로 고정 — 이 섹션 전용).
- 별 아이콘은 넣지 않는다(섹션 제목이 이미 말함). 설명 한 줄 없음.

### 4.5 밀도·문구 원칙

- 홈 전체에 숫자 강조(큰 숫자 카드, 퍼센트 원형 차트) 없음. 숫자는 `text-xs`/`text-[13px]` + `tabular-nums`.
- 문구는 평서문·짧게. 재촉하는 말("서두르세요", "!") 없음. 지남도 "밀린"이 아니라 "지남"으로 표기(탭 빈 상태 문구만 "밀린 할 일이 없습니다").
- 섹션 제목: "오늘", "이번 주", "분기 목표", "다시 볼 별", "이어 읽기", "진행 중인 연구", "최근 생각", "최근 세미나".

## 5. 주간 회고 자동 초안

새 주간 회고를 만들 때 **한 번** 본문에 넣는다(기존 `reviewTemplate("week")`의 "## 회고 메모" 앞). 이후 다시 채우지 않는다. 대상 기간 = 그 회고의 ISO 주(월 00:00 ~ 일 23:59, 로컬).

```markdown

- 2장 초안 — 논문 A 작성
- 지도교수 미팅 준비 — 논문 A 작성
- 장비 신청

### 끝난 프로젝트 1
- 데이터 정리 파이프라인

### 새로 만든 항목 7
- 논문 · Attention Is All You Need
- 생각 · 모델 크기와 데이터 양의 관계
- 세미나 · 11월 랩 세미나

## 회고 메모

```

- 소제목 뒤 숫자는 개수(괄호 없이 한 칸 띄움 — 앱의 "완료 3" 표기와 같음).
- **비어 있는 묶음은 통째로 뺀다.** 세 묶음이 모두 비면 "## 이번 주 모음" 자체를 넣지 않는다(기존 양식 그대로).
- 할 일: `제목 — 소속 제목`(소속 없으면 제목만). 완료 시각 순.
- 새로 만든 항목: `종류 · 제목`, 종류 순서 논문 → 세미나 → 생각 → 프로젝트 → 목표, 그 안에서 만든 순. 할 일·회고 자체는 넣지 않는다.
- 묶음당 **최대 15줄**, 넘으면 마지막 줄 `- 외 n개`.

- `[[위키링크]]`는 **쓰지 않는다** — 초안 하나가 수십 개 본문 링크(그래프 `body` 선·백링크)를 만들어 그래프와 연결 목록을 어지럽힌다. 사용자가 원하면 직접 링크로 바꾼다.
- 기울임 안내 문장 한 줄은 에디터에서 `text-muted`로 보이지 않으므로 평범한 이탤릭으로 둔다(지워도 됨).

## 6. 빠른 캡처

### 6.1 단축키 (확정)

**`C`** (Capture). 기존 전역 규칙(`resolveShortcut`)과 똑같이: 입력 중·대화상자 열림·IME 조합 중·⌘/Ctrl/Alt 함께 누름이면 무시. 한글 입력 상태에서도 되도록 `code === "KeyC"`도 받는다(`N`·`G`와 같은 방식).

- 계획서 예시 `Shift+N`은 **쓸 수 없다**: 현재 `isN`이 `key === "N"`과 `code === "KeyN"`을 Shift와 상관없이 받아 "새 항목"으로 이동한다.
- 기존 키와 겹침 점검: `N`(새 항목) · `/`(빠른 입력/그래프 검색) · `G`(그래프) · `⌘/Ctrl+K`(검색) · 그래프 캔버스 안 `[` `]` `+` `−` `0` · 브라우저 `Ctrl+C`(수정키가 있으면 무시하므로 복사와 충돌 없음). `C`는 비어 있다.
- 홈에서도 `C`는 캡처 창을 연다(`/`는 홈 입력창 포커스로 그대로).
- 보조 경로: Cmd+K 팔레트에 명령 "빠른 캡처" + 오른쪽 `<Kbd>C</Kbd>`. 사이드바 맨 아래 단축키 안내가 있다면 같은 줄에 추가.

### 6.2 창

기존 `Dialog`(네이티브 `<dialog>`, 포커스 가둠·Esc·바탕 클릭 닫기) 그대로, 위치만 화면 위쪽(`mt-[15vh] mb-auto`)으로 — 팔레트와 같은 자리라 시선이 흔들리지 않게. 폭 `w-[min(32rem,calc(100vw-2rem))]`.

```
┌ 빠른 캡처 ─────────────────────────── [생각│링크] ┐
│ ┌────────────────────────────────────────────┐ │
│ │ 떠오른 생각을 적으세요                      │ │  textarea 3줄
│ └────────────────────────────────────────────┘ │
│ 수집함에 저장됩니다.            ⌘Enter 저장  [저장] │
└────────────────────────────────────────────────┘
```

- 제목 `h2` "빠른 캡처" `text-base font-semibold`. 오른쪽에 종류 세그먼트 `[생각 | 링크]`(graph.md 7절 세그먼트의 작은 판: 바깥 `h-7`, 버튼 `h-6 px-2.5 text-xs`, `role="radiogroup" aria-label="종류"`, ←/→).
- **생각**: `<textarea rows=3>`(`controlClass`, `text-[15px]`, 최대 높이 12줄 후 스크롤), placeholder "떠오른 생각을 적으세요". 저장 = 기존 `createQuickThought`(메모 · 씨앗)와 같은 규칙.
- **링크**: 위 `<input type="url">` placeholder "https://…", 아래 `<input>` 메모(선택) placeholder "왜 저장하나요? (선택)". 수집함 생각으로 저장, 제목 = 메모가 있으면 메모 첫 줄, 없으면 URL의 도메인+경로(60자). 본문에 URL.
- **자동 전환**: 생각 칸에 붙여넣은 글 전체가 `http(s)://` 하나뿐이면 링크로 바꾸고 URL 칸에 넣는다. 화면 아래 상태줄에 "링크로 바꿨습니다." — 사용자는 세그먼트로 되돌릴 수 있다. 직접 타이핑은 자동 전환하지 않는다.
- DOI·arXiv 링크여도 이 창에서는 논문을 만들지 않는다(조용하게, 한 가지 일만). 상태줄 오른쪽에 `ghost sm` "논문으로 추가 →"(`/papers/new?url=…`, 기존 `FillFromLink` 경로)만 보인다.
- 열 때마다 마지막 종류를 기억하지 않고 **생각**으로 연다. 열리면 첫 입력에 포커스.

### 6.3 키

| 키 | 동작 |
|---|---|
| `⌘/Ctrl+Enter` | 저장 (생각 textarea에서 `Enter`는 줄바꿈) |
| 링크 칸 `Enter` | 저장 |
| `Esc` | 닫기. 내용이 있으면 닫지 않고 상태줄에 "Esc를 한 번 더 누르면 지웁니다." → 2초 안에 다시 `Esc`면 닫기 |
| `Tab` | 세그먼트 → 입력 → (메모) → 저장 버튼 |

### 6.4 저장 후 피드백

- 저장되면 **창을 닫고** 포커스를 열기 전 요소로 돌려준다(네이티브 dialog 기본 동작).
- 화면 오른쪽 아래 작은 알림(토스트 부품이 없으면 이것 하나만 새로 만든다): `fixed bottom-4 right-4 rounded-lg border border-border bg-bg px-3 py-2 text-[13px] shadow-overlay`, 글 "수집함에 저장했습니다." + `underline` 링크 "보기"(`/inbox`). **3초** 뒤 사라짐, hover·포커스 중엔 멈춤. `role="status"`(aria-live polite). reduced motion이면 나타남·사라짐 전환 없음.
- 연달아 적고 싶을 때를 위해 `⇧⌘Enter`(Shift+⌘/Ctrl+Enter)는 저장 후 창을 **유지·비움**, 상태줄에 "저장했습니다. 이어서 적으세요."
- 저장 중: 저장 버튼 `Spinner` + 입력 `readOnly`(disabled 아님 — 포커스 유지, `QuickInput`과 같음). 실패: 창 유지, 상태줄 `text-danger` 오류 문구, 입력 보존.
- 상태줄: 창 아래 왼쪽 `text-xs text-muted`, `aria-live="polite"`, 기본 글 "수집함에 저장됩니다."

|---|---|---|---|
| 할 일 (미완료) | □ 빈 정사각형 (체크 상자) | 채움 `canvasBg`, 테두리 `gray4` 1.25s, 모서리 0.75g | 3 고정 |

**2.2 크기**: 회고·주제와 같이 `degree`와 상관없이 3 고정.

**2.3 상태**: 완료 할 일 라벨 뒤에 ` · 완료`. 보관된 부모의 할 일은 부모와 같이 "보관 보기"에서만.

**3절 선**: 할 일 → 부모 = `belongs`(기존 굵기·투명도 그대로). 할 일은 다른 선을 갖지 않는다.

**5절 라벨**: 확대 기준은 "논문·세미나·생각·회고·주제"와 같은 줄(k ≥ 2.0 / 노드 > 300이면 2.5). 겹침 우선순위는 맨 뒤(주제 다음).

**6.2 필터 바**: 칩 순서 `… 생각✔ │ 회고☐ 주제☐ 할 일☐` — 할 일은 **기본 꺼짐**. 칩 아이콘은 빈 정사각형. 할 일 칩을 켜도 완료된 할 일은 보이지 않고, 칩 오른쪽에 체크박스 "완료 포함"이 나타난다(할 일 칩이 꺼져 있으면 숨김). URL 쿼리 `types=…,task&doneTasks=1`.

**6.4 미리보기**: 배지 `Badge tone="gray"` "할 일". 속성: 마감일(1절 `formatDue` 표기와 색) · 소속. 요약 없음. "열기" 버튼은 **소속 화면으로**(소속 없음이면 `/tasks?tab=by-parent`), 라벨 "소속 열기".

**7.2 PARA 배치**: 할 일은 자기 열이 없다. `forceX` 목표 = 부모 노드가 있는 열 중심 **+ 70g**(부모 오른쪽 곁), strength 0.6; 소속 없음이면 프로젝트 열 중심 + 70g. 열 제목은 추가하지 않는다.

**8절 로컬 그래프**: 프로젝트·목표·영역 상세의 로컬 그래프에도 할 일은 기본으로 그리지 않는다(상세에 이미 할 일 목록이 있음).
