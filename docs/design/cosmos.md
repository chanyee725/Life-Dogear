# 우주 보기 시각 규칙 (단계 C)

> 근거: `docs/PLAN-COSMOS.md`(승인, C1~C4), `docs/design/graph.md`(기본 그래프 — **그대로 유지**), `src/app/globals.css` 토큰, `src/components/graph/graph-theme.ts`.
> 대상: 구현자 C. 값은 그대로 옮겨 쓰면 되도록 숫자로 적었다. 이 문서에 없는 규칙(단위 g/s, 모양, 키보드, 확대 범위, 라벨 길이, 빈 상태 등)은 **graph.md를 그대로** 따른다.
> 원칙: 기본 그래프는 조용한 무채색, 우주 보기는 **영역 색 + 발광 + 어두운 바탕**. 둘은 같은 데이터·같은 모양·같은 키보드를 쓰고 색과 힘만 다르다.

## 0. 대비 계산 기준

- 대비는 WCAG 2 상대 휘도 공식으로 계산했다. 기준 바탕은 `space` `#0b0e1a`.
- 노드(그래픽) 3:1 이상, 글자 4.5:1 이상. 흐려진(비활성) 노드·선은 graph.md와 같이 예외.
- 팔레트는 OKLCH로 만들고(밝기 0.66~0.90) 이웃 색끼리 밝기를 엇갈려 색각 이상에서도 명도 차가 나게 했다. OKLab 거리 최소 0.069(청록·민트, 9·10번째라 영역이 9개 넘을 때만 같이 나온다).

- **노드의 영역 정하기**(색·클러스터 공통):
  1. 노드에 `areaId`가 있으면(프로젝트·목표) 그것.
  2. 영역 노드 자신은 자기 영역.

  4. 그래도 없으면 "영역 없음"(`neutral`). 회고·주제는 항상 `neutral`.
- `GraphNode`에 지금 없는 값(영역 순서)은 응답에 `areas: { id, title, sortOrder }[]`를 더하거나 클라이언트에서 영역 노드로 계산한다 — 방법은 구현자 판단.

## 2. 배경

### 2.1 바탕

- 캔버스 전체 `space` 단색. 그라데이션 바탕은 쓰지 않는다(라벨 대비 계산을 단순하게).
- **성운(은하 안개)**: 영역마다 그 영역 노드들의 무게중심에 원형 그라데이션 하나. 반지름 = (중심에서 가장 먼 소속 노드까지 거리) + 40g, 최소 80g. 색은 영역 색, 중심 알파 **0.07** → 가장자리 0. 노드 3개 미만 영역은 그리지 않는다. 노드 > 1500이면 끈다.
  - 가장 밝은 성운(민트 0.07) 위에서도 `label` 대비 10:1 이상, 노드 대비 3:1 이상이 유지된다.
- 성운은 시뮬레이션이 멈춘 뒤(`onEngineStop`) 한 번 계산해 저장하고, 노드가 끌려 움직일 때만 다시 계산한다.

### 2.2 배경 별

배경 별은 **그래프 캔버스 뒤의 별도 `<canvas>`**(화면 좌표, `pointer-events: none`)에 그린다. 그래프 캔버스는 `backgroundColor="transparent"`, 래퍼 CSS 배경이 `space`. 이렇게 하면 별이 움직여도 그래프를 매 프레임 다시 그리지 않는다.

| 항목 | 값 |
|---|---|
| 밀도 | 화면 1,000px²당 0.12개 → 1440×900에서 약 155개. **최대 400개**, 최소 60개 |
| 크기 (반지름, 화면 px) | 70%: 0.5~0.9 / 25%: 0.9~1.3 / 5%: 1.3~1.7 (구간 안은 균등 난수) |
| 밝기 (알파) | 0.20~0.70 균등, 크기 1.3 이상인 별은 0.55~0.85 |
| 색 | 75% `starWhite`, 15% `starBlue`, 10% `starWarm` |
| 반짝임 | 별 8%만: 알파 ±0.15, 주기 4~7s(별마다 난수), 사인 곡선 |
| 흐름 | 모든 별이 화면에서 **방향 (−0.96, 0.28)로 초당 4px**. 화면 밖으로 나가면 반대편으로 되감기(wrap) |
| 패럴랙스 | 그래프를 팬하면 별은 팬 거리의 **0.08배**만 같이 움직인다. 확대해도 별 크기·밀도는 그대로 |
| 프레임 | `requestAnimationFrame`, **30fps로 제한**(프레임 건너뛰기). 탭이 숨겨지면(`document.hidden`) 멈춤 |
| 씨앗 | 별 배치는 고정 씨앗 난수(예: `mulberry32(42)`) — 새로고침해도 같은 하늘 |
| 크기 변화 | 창 크기가 바뀌면 밀도에 맞게 다시 뿌린다(200ms 디바운스) |

- **`prefers-reduced-motion: reduce`**: 흐름·반짝임·패럴랙스 모두 끄고 한 번만 그린 정지 화면. rAF 루프를 돌리지 않는다.
- 노드는 정착 후 움직이지 않는다(포커스·클릭 대상이 흔들리지 않게). "흐름"은 배경 별만 담당한다.

## 3. 노드

### 3.1 모양 — 기본 그래프와 동일

graph.md 2.1의 모양·테두리 두께·모양 크기 환산을 그대로 쓴다. 바뀌는 것은 **색**과 **크기 공식**, 그리고 **발광**뿐이다.

| 종류 | 모양 (그대로) | 우주 보기 색 |
|---|---|---|
| 인생 목표 | ● 원 + 바깥 링 | 태양 (3.4절) |
| 연 목표 | ● 원 | 채움 `gold` |
| 분기 목표 | ◯ 원 | 채움 `space`, 테두리 `gold` 1.5s |
| 영역 | ■ 둥근 정사각형 | 채움 영역 색 |
| 프로젝트 | ◆ 마름모 | 채움 영역 색 |
| 논문 | ● 원 | 채움 영역 색 |
| 세미나 | ▲ 삼각형 | 채움 영역 색 |
| 생각 | ◯ 고리 | 채움 `space`, 테두리 영역 색 2s |
| 회고 | ▪ 작은 정사각형 | 채움 `neutral` |
| 주제 | ◇ 빈 마름모 | 채움 `space`, 테두리 `neutral` 1.25s |

### 3.2 크기·밝기 (중요도 `s` ∈ [0, 1], 8절)

```
r       = min(base × (0.85 + 0.9 × s), 18)     // base = graph.md 2.1 기본 반지름 (g)
alpha   = 0.75 + 0.25 × s                     // 노드 채움·테두리 알파
```
- 회고·주제는 기본 그래프처럼 `r = 3.5` 고정, `alpha = 0.75` 고정.
- 인생 목표는 3.4절 고정 크기.
- `alpha` 최저 0.75에서도 가장 어두운 밤색이 3.8:1 — 모든 노드 3:1 충족(1.1 표 마지막 열).
- 연결 수(degree)는 크기 공식에 직접 넣지 않는다(중심성으로 점수에 이미 들어 있다).
- 노드 > 1500이면 `base −1`(최소 3), graph.md와 같음.

### 3.3 발광 (glow)

노드 뒤에 원형 그라데이션 한 장. `ctx.shadowBlur`는 노드가 많으면 느리므로 쓰지 않는다 — **색별로 미리 그린 오프스크린 스프라이트**(64×64, 중심 알파 1 → 가장자리 0, 이차 감쇠 `a(t) = (1 − t)²`)를 `drawImage`로 늘려 그리고 `globalAlpha`로 세기를 준다.

```
glowRadius = r × (1.8 + 1.7 × s)           // g, 노드 중심에서
glowAlpha  = 0.10 + 0.30 × s               // 스프라이트 중심 알파
```
- 합성은 기본 `source-over`(겹친 곳이 하얗게 타지 않게). `lighter`는 쓰지 않는다.
- `s < 0.15`면 발광 생략(작은 별은 점으로만).
- 노드 > 1500이면 `s ≥ 0.5`만 발광.
- 흐려진 노드(6절 R)는 발광 끔.
- 그리는 순서: 성운 → 선 → 발광 → 노드 → 라벨.

### 3.4 인생 목표 — 태양

| 요소 | 값 |
|---|---|
| 반지름 `r` | **14g 고정**(점수와 무관). 인생 목표가 4개 이상이면 12g |
| 채움 | 원형 그라데이션 `goldCore`(중심) → `gold`(`r`의 100%) |
| 링 | graph.md와 같은 "원 + 바깥 링": `gold` 1.5s, 노드 가장자리에서 3g 바깥 |
| 코로나(발광) | `glowRadius = r × 4.5`, `glowAlpha = 0.45`, 색 `gold` |
| 위치 | 4절 — 은하 원의 한가운데 |
| 라벨 | 확대 배율과 상관없이 **항상** 표시, `labelStrong`, 굵기 600, 글자 13px |

- 태양은 맥동하지 않는다(정지). 움직임은 배경 별만.
- 상태가 `achieved`/`dropped`인 인생 목표는 태양 대신 일반 연 목표 모양(●, `gold`, `r = 9`)으로 그리고 중심 고정도 푼다.

### 3.5 상태 (graph.md 2.3 그대로, 색만 바꿈)

| 상태 | 우주 보기 |
|---|---|
| 보관 | 알파 0.45, 발광 끔, 라벨 ` · 보관` |
| 키보드 포커스 | `focus` 링 2s, 가장자리에서 3s 바깥, 라벨 항상 |
| 선택 | 포커스 링과 같음 + 6절 별자리 강조 |
| 중요 별표 | 노드 오른쪽 위(중심에서 45°, `r + 2g`)에 4각 별 ✦ 화면 7px, `goldCore`. 확대 k < 0.8이면 생략 |

## 4. 클러스터 힘 (은하 배치)

우주 보기는 **자유 배치를 바탕으로** 영역 힘을 더한다. PARA 배치는 우주 보기에서 쓰지 않는다(7절 — 배치 세그먼트 숨김).

| 힘 | 값 |
|---|---|
| 은하 중심(앵커) | 영역 `i` (0부터, 1.1 순서) → 반지름 `R = 220 + 30 × N`g인 원 위, 각도 `θ = −90° + 360° × i / N` (N = 보이는 영역 수, 맨 위에서 시계 방향). N = 1이면 (`R`, 0) |
| 영역으로 당김 | 영역이 있는 노드: `forceX(ax) / forceY(ay)` **strength 0.12** |
| 영역 노드 자신 | 앵커에 strength **0.5**(은하의 핵) |
| 영역 없는 노드 | 영역 힘 없음, `forceRadial(R × 0.55)` strength **0.03**(은하 사이에 흩어짐) |
| 인생 목표 (태양) | 1개: `fx = 0, fy = 0` 고정. 2~3개: 반지름 50g 원 위에 고정. 4개 이상: 반지름 80g 원 위에 고정 |
| 연·분기 목표 | 영역 있으면 영역 앵커와 중심을 잇는 선의 **45% 지점**으로 strength 0.15, 없으면 `forceRadial(120)` strength 0.1 |
| 반발 `charge` | **−80** (`distanceMax 400`) |
| 선 길이 `link distance` | 소속 40 / 그 외 70 |
| 선 세기 `link strength` | 같은 영역끼리 기본값(d3 기본 `1/min(deg)`), **영역이 다른 노드끼리 0.02**(은하가 서로 끌어당겨 뭉개지지 않게) |
| 충돌 `collide` | `r + 6` |
| 정착 | 전환 시 `alpha 0.6` 재가열, `d3AlphaDecay 0.03`. reduced motion이면 `warmupTicks 150` 후 정지 상태로 바로 그림 |

- 저장된 `fx/fy`(자유 배치의 끌어 놓은 위치)는 우주 보기에서 **풀고**, 기본 보기로 돌아가면 복원한다(PARA와 같은 방식). 우주 보기에서 끌기는 그 순간만, **저장하지 않는다**. "배치 초기화" 버튼 숨김.
- 처음 진입·필터 변경 뒤 화면 맞춤(4.1). 시뮬레이션이 멈출 때까지 기다리지 않는다: 보이지 않게 `warmupTicks 80`을 돌린 뒤 **곧바로 맞춤(0ms)**, 멈췄을 때(`onEngineStop`)는 그래프 범위가 15% 넘게 커졌을 때만 다시 맞춤(400ms, reduced motion 0).

### 4.1 화면 맞춤 — 빈 영역 기준

"화면에 맞춤"(버튼·`0` 키), 첫 진입 맞춤, 선택 시 이동은 모두 캔버스 전체가 아니라 **오버레이를 뺀 빈 영역**을 기준으로 한다.

| 쪽 | 빼는 폭 |
|---|---|
| 왼쪽 | 옆 패널(7.3)이 펼쳐져 있으면 **320px** (16 + 288 + 16), 접혀 있으면 0 |
| 오른쪽 | 미리보기가 열려 있으면 **352px** (16 + 320 + 16), 닫혀 있으면 0 |
| 위·아래 | 0 (여백 `padding 64s`는 빈 영역 안에서 그대로) |

- 맞춤: 그래프 범위를 빈 영역(폭 = 캔버스 폭 − 왼쪽 − 오른쪽) 안에 `padding 64s`로 넣고, 중심을 빈 영역의 가운데에 둔다.
- 빈 영역 폭이 320px보다 좁으면 오른쪽 빼기만 적용하고 왼쪽은 0으로 본다(좁은 화면에서 그래프가 사라지지 않게).
- 패널을 접거나 펼치고 미리보기를 열거나 닫을 때는 자동으로 다시 맞추지 않는다(선택 이동은 6.2의 규칙을 따름).

## 5. 선

| 종류 | 모양 (그대로) | 굵기 (s) | 색 · 알파 |
|---|---|---|---|
| 소속 `belongs` | 실선 | 1.25 | **자식 노드의 영역 색** · 0.35 (영역 없음은 `edge` · 0.30) |
| 연결 `link` / 본문 `body` | 실선 | 0.75 | `edge` · 0.14 |
| 주제 `topic` | 점선 `[2, 3]`s | 0.75 | `edge` · 0.12 |

- 노드 > 1500: 소속 1s · 0.28, 나머지 0.5s · 0.08.
- 화살표 없음, 겹치는 `link`/`body` 한 줄 — graph.md와 같음.

## 6. hover·선택 — 별자리 경로

### 6.1 hover

graph.md 4절과 같은 구조(H·이웃 N·나머지 R). 값만:

| 대상 | 노드 알파 | 발광 | 라벨 |
|---|---|---|---|
| H | 1 | 그대로 | `labelStrong`, 500 |
| N | 1 | 그대로 | `label` |
| R | **0.15** | 끔 | 숨김 |

선: H에 붙은 선 알파 0.70, 굵기 +0.5s / 나머지 선 0.03. 전환 120ms(reduced motion 즉시).

### 6.2 선택 = "왜 중요한가" 별자리

노드 **S**를 클릭(또는 Enter)하면 S에서 인생 목표까지 **소속(`belongs`) 선만 따라 위로** 올라간 경로를 별자리처럼 강조한다. 항목 → 프로젝트 → 분기 목표 → 연 목표 → 인생 목표.

- 경로 찾기: S에서 부모 방향(`source`=자식 → `target`=부모) BFS, `belongs`만. **인생 목표에 닿지 않는 갈래는 뺀다**(예: 프로젝트 → 영역 소속 선은 경로가 아니다). 닿는 갈래가 하나도 없을 때만 닿은 데까지 그린다(아래). S가 프로젝트에 직접 속하지 않는 논문·생각이면 첫 걸음만 `link`/`body`로 이어진 **프로젝트**(여럿이면 모두)에서 시작한다. 갈래가 여럿이면 모든 경로의 합집합.
- 경로 노드 집합 **P**(S 포함), S의 직접 이웃 중 P가 아닌 것 **N**, 나머지 **R**.

| 대상 | 노드 알파 | 발광 | 라벨 |
|---|---|---|---|
| S | 1 | `glowAlpha + 0.15` | `labelStrong` 600, 항상 |
| P (S 제외) | 1 | 그대로 | `labelStrong` 500, 항상 |
| N | 0.55 | 끔 | `label`, 항상 |
| R | **0.12** | 끔 | 숨김 |

| 선 | 굵기 (s) | 색 · 알파 |
|---|---|---|
| 경로 선 (P 안의 소속 선 + 첫 걸음 연결 선) | **2.5** | `path` · **0.95**, 그 아래 같은 색 굵기 **7s · 0.22** 한 번 더(선 발광) |
| S와 N 사이 선 | 1 | `edge` · 0.35 |
| 나머지 선 | 그대로 | 알파 **0.03** |

- **흐림 비율 요약**: 경로·선택 = 100%, 이웃 = 55%, 나머지 노드 = 12%, 나머지 선 = 3%. 배경 별·성운은 흐리지 않는다.
- 경로 그리기 애니메이션: S에서 태양 쪽으로 선이 **450ms**(ease-out)에 걸쳐 그어진다(`setLineDash`의 오프셋 보간). reduced motion이면 즉시.
- 경로가 인생 목표에 닿지 않으면 닿은 데까지만 그린다. 미리보기(6.3)에 문구로 알린다.
- 선택 중 **캔버스에서 직접** hover하면 graph.md처럼 hover가 잠시 우선, 손을 떼면 별자리로 돌아간다.
- **옆 패널 행의 hover·포커스는 선택이 있는 동안 무시한다** — 별자리가 항상 유지된다. 행 클릭·Enter 때 패널에서 온 hover도 지운다. 선택이 없을 때만 패널 행 hover가 캔버스 hover 강조(6.1)를 일으킨다.
- 선택 시 카메라: 경로 노드 P(와 S) 중 하나라도 빈 영역(4.1) 밖이면, P 전체를 빈 영역에 맞춘다(300ms, reduced motion 0). 이때 확대 배율은 지금보다 **키우지 않는다**(줄이기만). 모두 안에 있으면 움직이지 않는다.

### 6.3 미리보기 패널 추가 내용

graph.md 6.4 패널을 그대로 쓰되, 우주 보기에서는 제목 아래(속성 위)에 **"왜 중요한가"** 블록을 넣는다. 색이 아닌 글로도 같은 정보를 준다(화면 읽기 대체 경로).

```
중요도 0.82 · 3위                         ← text-[13px] text-fg tabular-nums, "3위"는 text-muted
[직접 0.90] [연결 0.64] [최근 0.41] [★ 중요]   ← 칩 h-6 px-2 rounded-md bg-subtle text-xs text-muted
논문 X → 프로젝트 Y → 2027 목표 → 인생 목표 Z    ← text-[13px] text-muted, 각 이름은 클릭 시 그 노드 선택
```
- 경로가 끊기면 마지막 줄 대신 "아직 인생 목표와 이어지지 않았습니다." (`text-[13px] text-muted`).
- 머리줄 닫기 버튼 왼쪽에 별표 토글: `ghost icon` 28×28, `aria-pressed`, `aria-label` "중요 표시"/"중요 표시 해제", 아이콘 ☆/★(켬은 `text-fg`). 툴팁 "중요 표시하면 우주 보기에서 더 밝게 보입니다".
- `aria-live` 문장(graph.md 11.1)에 덧붙임: 선택 시 "미리보기 열림. 중요도 {0.82}, 인생 목표까지 {3}단계."

## 7. 화면 — 토글·옆 패널

### 7.1 기본 ↔ 우주 토글

- 위치: 상단 바 오른쪽, **배치 세그먼트 왼쪽**. 둘 사이 `gap-2`.
- 모양: graph.md 7절 세그먼트 컨트롤과 같은 클래스. `role="radiogroup" aria-label="보기"`, 버튼 `role="radio" aria-checked`, ←/→.
- 문구: **`[기본 | 우주]`**. 우주 버튼 앞에 ✦ 아이콘 12px(`aria-hidden`).
- 우주 보기일 때 배치 세그먼트 `[자유 배치 | PARA 배치]`와 "배치 초기화"는 **숨긴다**(우주는 자체 배치). 기본으로 돌아가면 이전 배치 선택을 복원.
- URL: `?mode=cosmos`(기본은 쿼리 없음). 기존 `view=para`와 별개. `localStorage` 키 `rb-graph-mode`에 마지막 선택을 저장, URL에 `mode`가 없으면 그것을 따른다.
- `aria-live`: 전환 시 "우주 보기" / "기본 보기".

```
┌────────────────────────────────────────────────────────────────────────────┐
│ 그래프  노드 128 · 선 214          [기본│✦ 우주]  목표 지도로 보기             │ ← 상단 바(앱 테마 그대로)
├────────────────────────────────────────────────────────────────────────────┤

│ │ 중요한 별   │      ·   ☀   ·                              │              │ │
│ │ 외톨이 별   │  ·        ·      ˙                          └──────────────┘ │

│ └─────────────┘                                                            │

```

### 7.2 캔버스 영역의 테마

- 상단 바·필터 바는 **앱 테마 그대로**(라이트면 라이트).
- 캔버스 래퍼(캔버스 + 그 위 DOM 오버레이 전체)에 `class="dark"`를 붙인다. globals.css가 `.dark` 하위 트리에도 다크 토큰을 적용하므로(`@custom-variant dark (&:where(.dark, .dark *))`), 미리보기·검색·확대 버튼·옆 패널이 **새 CSS 없이** 다크 토큰으로 그려진다. 래퍼 배경은 `space` 인라인 스타일.
- 다크 토큰 대비 확인: `--rb-muted #9d9da6`는 `--rb-bg #141416` 위 6.8:1, `spaceRaised #121729` 위 6.6:1 — 보조 글자 4.5:1 충족. `text-faint`는 여기서도 쓰지 않는다.
- 오버레이 패널 바탕: 기존 `bg-bg`(다크 `#141416`) 그대로 + `border-border`. 캔버스와 구분이 약하면 `bg-bg/95` 정도까지만(블러·그림자 추가 없음).
- 포커스 표시(래퍼 outline)는 다크 `accent` `#8b94f0`(`space` 위 7.0:1).

### 7.3 옆 패널 (우주 보기 전용)

- 위치: 캔버스 위 **왼쪽** 오버레이. `top 16, left 16`, 폭 **288px**, 최대 높이 `calc(100% − 32px − 40px)`(아래 검색 힌트 자리 40px 비움), 넘치면 패널 안 스크롤.
- 상자: `rounded-lg border border-border bg-bg p-4 flex flex-col gap-5`, `role="complementary" aria-label="우주 요약"`.
- 머리줄: "우주 요약" `text-sm font-semibold` + 오른쪽 접기 `ghost icon` 28×28(`aria-expanded`, `aria-label` "우주 요약 접기"/"펼치기"). 접히면 머리줄만 있는 `h-11` 알약. 접힘은 `localStorage` `rb-cosmos-panel` = `"collapsed"`.
- 검색 힌트(graph.md 6.3)는 패널과 겹치지 않게 그대로 왼쪽 아래 16px(패널이 위 자리만 쓴다).
- 메인 폭 < 900px: 기본 접힘.

섹션 3개, 각 섹션:
- 소제목 줄: `text-xs font-medium text-muted` 제목 + 오른쪽 `text-xs text-muted tabular-nums` 개수.
- 행: `<button>` `h-8 px-2 -mx-2 rounded-md hover:bg-hover flex items-center gap-2 text-[13px]`. 모양 아이콘 10×10(우주 색) + 제목 `truncate text-fg` + 오른쪽 보조값 `text-xs text-muted tabular-nums`.
- 행 클릭/Enter: 그 노드를 **선택**(별자리 강조 + 미리보기). 카메라는 6.2의 선택 시 카메라 규칙(빈 영역 기준). 행 hover·포커스는 선택이 없을 때만 캔버스에서 그 노드를 hover 강조하고, 선택이 있으면 무시한다(6.2).
- 패널 안은 일반 Tab 순서(행마다 하나). 캔버스 화살표 키와 무관.

| 섹션 | 제목 | 내용 | 행 보조값 | 개수 | 비었을 때 |
|---|---|---|---|---|---|
| 1 | **중요한 별 Top 10** | 점수 내림차순 상위 10개(인생 목표 제외 — 이미 태양) | 순위 `1`…`10` 왼쪽 `w-4 text-muted`, 오른쪽 점수 `0.82` | 10 | "아직 점수를 매길 항목이 없습니다." |
| 2 | **외톨이 별** | 선이 0개인 항목(회고·주제 제외), 최근 수정 순 | 종류 이름("논문") | 최대 8 + "+ n개 더"(누르면 필터 "연결 없는 항목만" 켜고 기본 보기로) | "외톨이 별이 없습니다. 모두 어딘가에 이어져 있어요." |
| 3 | **오래 손대지 않은 중요한 별** | 점수 ≥ **0.55** 이면서 마지막 활동이 **45일** 넘게 지난 항목(목표·영역 제외), 오래된 순 | "62일 전" | 최대 5 | "중요한 항목을 모두 최근에 살펴봤습니다." |

- 섹션 3 아래 도움말 한 줄: "오래된 순. 열어서 다시 살펴보세요."

## 8. 중요도 점수 (C2)

순수 함수 `importanceScore(node, ctx) → { score, direct, centrality, recency, starred }`. 모든 값 0~1.

### 8.1 합치기

```
score = 0.40 × direct + 0.25 × centrality + 0.20 × recency + 0.15 × starred
if (starred) score = max(score, 0.70)
if (archived) score = score × 0.5
score = clamp(score, 0, 1)
```
- 별표는 가중합에도 들어가고, 별표 항목은 **최소 0.70**(Top 10에 거의 들어가게)으로 끌어올린다.
- 점수는 **현재 화면에 보이는 그래프**(필터 적용 후) 기준으로 계산한다. 중심성 정규화도 그 그래프 안에서.

### 8.2 직접 값 `direct`

| 종류 | 값 |
|---|---|
| 인생 목표 | 1.00 |
| 연 목표 | 0.80 |
| 분기 목표 | 0.65 |
| 목표 상태 보정 | `achieved` × 0.6, `dropped` × 0.2 |
| 영역 | 0.60 |
| 프로젝트 `active` | 0.60, 마감 14일 이내 또는 지남 +0.30 (상한 1) |
| 프로젝트 `on_hold` | 0.30 |
| 프로젝트 `done` | 0.25 (마감 가산 없음) |
| 논문 `core`(핵심) / `reference`(참고) / `light`(가볍게) | 0.90 / 0.50 / 0.20 |
| 세미나 | 0.40 |
| 생각 `seed` / `growing` / `refined` | 0.30 / 0.45 / 0.60 |
| 회고 | 0.20 |
| 주제 | 0.15 |

### 8.3 연결 중심성 `centrality`

- **PageRank**, 무방향, damping **0.85**, 최대 **40회** 반복 또는 변화 합 < 1e-6이면 종료.
- 선 가중치: 소속 1.0, 연결·본문 0.8, 주제 0.3.
- 정규화: `centrality = sqrt(pr / max(pr))` (제곱근으로 작은 값들을 펴 준다).
- 노드 5개 미만이면 PageRank 대신 `sqrt(degree / max(degree))`, 선이 하나도 없으면 0.

### 8.4 최근 활동 `recency`

```
t       = (now − lastActivity) / 1일                // lastActivity = max(updated_at, last_read_at)
recency = 0.5 ^ (t / 30)                            // 반감기 30일
```
- 30일 → 0.50, 60일 → 0.25, 90일 → 0.125. 미래 시각은 `t = 0`.
- 목표·영역은 `recency`를 **0.5로 고정**(오래 유지되는 구조라 최근 활동으로 벌하지 않는다).
- `GraphNode`에 `updatedAt`, `lastReadAt`(논문), 직접 값 계산용 필드(`importance`, `status`, `dueDate`, `maturity`, `starred`)가 필요하다 — 응답 확장은 구현자 판단.

### 8.5 별표

- 항목별 불리언. 저장은 새 테이블 `item_stars`(마이그레이션 `0003`, **CREATE TABLE만** — 기존 테이블은 바꾸지 않음). 행이 있으면 별표, 없으면 별표 아님. 루트 DB 미적용, 보고에 "마이그레이션 필요".

### 8.6 단위 테스트 기준값 (예시)

| 항목 | direct | centrality | recency | starred | 점수 |
|---|---|---|---|---|---|
| 핵심 논문, 중심성 0.5, 15일 전 | 0.90 | 0.50 | 0.707 | 0 | 0.360 + 0.125 + 0.141 = **0.626** |
| 진행 중 프로젝트 마감 7일, 중심성 1, 오늘 | 0.90 | 1.00 | 1.00 | 0 | 0.36 + 0.25 + 0.20 = **0.81** |
| 씨앗 생각, 외톨이, 90일 전, 별표 | 0.30 | 0 | 0.125 | 1 | 0.12 + 0 + 0.025 + 0.15 = 0.295 → **0.70** |
| 가볍게 논문, 보관, 중심성 0.2, 60일 전 | 0.20 | 0.20 | 0.25 | 0 | (0.08 + 0.05 + 0.05) × 0.5 = **0.09** |

## 9. 라벨

graph.md 5절(12px 고정, 아래 가운데, `textBaseline top`, 18자 잘림)을 따르고 색·기준만 바꾼다.

- 색 `label` `#c7cbd9`(11.9:1), 강조 `labelStrong` `#f3f4f8`(17.5:1).
- **가독성 테두리 필수**: 같은 글자를 `space` 색 `lineWidth 3.5s`로 먼저 stroke. 발광 한가운데(가장 밝은 코로나 위)에서는 바탕이 밝아져 테두리 없이는 3.4:1까지 떨어지므로, 테두리로 글자 주변을 `space`로 덮어 **11.9:1**을 확보한다.
- 확대 배율별 표시: graph.md 표에 더해 **점수 `s ≥ 0.6`인 노드는 "인생·연 목표, 영역" 줄과 같은 기준**(k ≥ 0.8, 노드 > 300이면 1.3)으로 일찍 보인다.
- **겹침 정리**: 노드 > 300일 때, 그리고 노드 수와 상관없이 **hover·선택 강조 중에는 항상** 켠다. 우선순위 순서로 라벨을 그리고, 이미 그린 라벨 상자(글자 상자 + 사방 2s)와 겹치면 건너뛴다.
  - 강조 중 우선순위: **선택 S > 경로 P > hover H > 이웃 N**. 그 밖 라벨은 강조 중 숨김(6절).
  - 평소(노드 > 300) 우선순위: 선택 > 경로 > hover > 이웃 > 태양 > 점수 높은 순.
  - 태양 라벨은 겹쳐도 건너뛰지 않는다. 경로 라벨끼리 겹치면 S에 가까운 쪽을 남긴다(경로 노드 자체는 그대로 보이고 이름은 미리보기 경로 글에 있다).
  - **선택 라벨과 태양이 겹칠 때 — 선택 라벨이 비킨다.** 태양 라벨은 항상 제자리(태양 아래 가운데)에 둔다. S 라벨의 기본 자리(노드 아래)가 태양 라벨 상자나 태양 원판(반지름 `r + 3g + 1.5s`, 링 포함)과 겹치면 아래 순서로 첫 번째 겹치지 않는 자리를 쓴다.
    1. **위**: 노드 위 가운데, 모양 윗가장자리에서 3s 위, `textBaseline = "bottom"`.
    2. **바깥 옆**: 태양 반대쪽 옆(S.x ≥ 태양 x면 오른쪽, 아니면 왼쪽). 노드 가장자리에서 6s 떨어져 세로 가운데(`textBaseline = "middle"`), 오른쪽이면 `textAlign left`, 왼쪽이면 `right`.
    3. 셋 다 겹치면 1(위)을 쓴다 — S 라벨은 빼지 않는다.
  - 같은 비키기 규칙을 태양과 겹치는 **경로 P 라벨**에도 쓴다(S가 먼저 자리를 잡고, P는 S·태양 둘 다 피해서). 비킨 뒤에도 다른 P 라벨과 겹치면 위의 "S에 가까운 쪽을 남긴다"를 따른다.
  - 자리를 바꿔도 글자 크기·색·테두리(3.5s)는 그대로.

## 11. 접근성

- **모양 유지**: 종류는 모양, 영역은 색 + 위치(은하) + 글(미리보기 영역 이름·패널)로 — 색만으로 구분하지 않는다.
- **대비**: 노드 최저 3.8:1(밤색, 알파 0.75), 라벨 11.9:1, 경로 선 15.4:1, 포커스 링 7.0:1, DOM 보조 글자 6.6:1 이상.
- **키보드**: graph.md 11.1 그대로(화살표·`[` `]`·Enter·Esc·`/`·`+` `−` `0`). Enter = 선택 = 별자리 강조. 처음 포커스는 **태양**(인생 목표 중 점수 최고), 없으면 점수 최고 노드.
- 토글은 radiogroup ←/→, 옆 패널 행은 일반 버튼(Tab).
- **대체 경로**: "목표 지도로 보기" 링크 유지 + 미리보기의 "왜 중요한가" 글 경로 + 옆 패널 목록(모두 DOM).
