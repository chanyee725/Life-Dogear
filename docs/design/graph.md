# 그래프 시각 규칙 (단계 G3)

> 근거: `docs/PLAN-GRAPH.md` 1절(원칙)·3절(노드·선)·4절(화면), `docs/PLAN-GRAPH-TEAM.md`, `docs/SPEC.md` 디자인 가이드, `src/app/globals.css` 토큰.
> 대상: 구현자 C (`src/app/graph/**`, `src/components/graph/**`). 값은 그대로 옮겨 쓰면 되도록 숫자로 적었다.
> 원칙 요약: **종류마다 은은한 색 + 모양으로 구분**(색 기준은 `[종류 | 영역]` 토글, 1절), 라벨은 확대·hover 때만, 그림자·그라데이션·애니메이션 장식 없음. (예전 "무채색 + 목표만 포인트 색" 규칙은 1절로 대체됐다.)

## 0. 단위와 좌표

- **그래프 단위(g)**: 확대 배율 `k = 1`일 때 1g = 1px. 노드 크기는 g 단위라 확대하면 같이 커진다(Obsidian과 같음).
- **화면 px(s)**: 확대와 상관없이 고정. 선 굵기·라벨 글자·포커스 링·hover 판정 여백은 s 단위. 캔버스에서는 `값 / globalScale`로 그린다.
- 확대 범위: `minZoom 0.2`, `maxZoom 6`. 처음 로드·필터 변경 뒤 `zoomToFit(400ms, padding 48s)`. reduced motion이면 0ms.

## 1. 색 토큰

캔버스는 CSS 변수를 직접 못 쓰므로 `src/components/graph/graph-theme.ts`에 라이트/다크 값을 상수로 두고, `<html>`의 `dark` 클래스 변화를 `MutationObserver`로 보고 바꿔 그린다. (globals.css에 새 CSS 변수를 추가하지 않는다. DOM 부분은 기존 Tailwind 토큰만 쓴다.)

> **바뀐 원칙(사용자 결정)**: 예전 "무채색 노드 + 목표만 포인트 색"을 버리고 **종류마다 색**을 준다. 색은 은은하게(채도 OKLCH C ≤ 0.19, 그라데이션·발광·네온 없음), 종류 구분은 여전히 **모양이 먼저**(2.1) — 색은 보조. 우주 보기(`cosmos.md`)는 이 절과 상관없이 그대로다.
> 대비는 WCAG 2 상대 휘도로 계산했다(라이트 바탕 `#ffffff`, 다크 바탕 `#141416`). 색각 이상(Machado 2009 제1·제2색각, 강도 1.0)으로 바꿔 본 뒤 OKLab 거리도 확인했다.

- 할 일은 배지가 회색이지만 회색 셋(회고·주제·할 일)이 겹치지 않게 **초록**(완료·달성 배지 green과 같은 계열 — "해낼 일" 느낌)으로 정했다. **할 일 배지는 회색 그대로**(관리자 결정): 검색 팔레트에서 green은 하이라이트가 쓰고 있고, "배지 색이 모두 다르다" 테스트가 있어 배지를 green으로 바꾸면 겹친다. 초록은 캔버스 노드에만 쓴다.
- 회고(따뜻한 회색)·주제(차가운 회색)는 일부러 채도를 낮춰 "구조 바깥의 보조 노드"로 물러나 보이게 했다.

### 1.3 색 기준 토글 `[종류 | 영역]`

- 위치: 필터 바(6.2) **맨 앞**. `text-[13px] text-muted` 라벨 "색" + 7절 세그먼트 컨트롤의 작은 판(`h-7`, 버튼 `h-6 px-2.5 text-[13px]`), 뒤에 묶음 구분선. `role="radiogroup" aria-label="색 기준"`, 버튼 `role="radio" aria-checked`, ←/→로 이동·선택. 폭 < 900px이면 필터 패널 맨 위.
- 상태는 URL 쿼리 `color=area`(기본 `kind`는 생략). URL에 없으면 마지막 선택(`localStorage` `rb-graph-color-by`). "필터 초기화"는 색 기준을 건드리지 않는다(필터가 아니라 보기 설정).
- 전환 시 다시 그리기만 한다(시뮬레이션 재가열 없음). `aria-live`로 "색: 종류" / "색: 영역".

**영역 기준일 때 노드 색** — 우주 보기 규칙(cosmos.md 1.1 "노드의 영역 정하기") 그대로:
1. `areaId`가 있으면(프로젝트·목표) 그 영역, 영역 노드는 자기 영역.
2. 없으면 선으로 바로 이어진 노드 중 `areaId`가 있는 노드의 **가장 많은 영역**, 동률이면 영역 없음. (할 일은 부모 하나뿐이라 부모 영역.)
3. 그래도 없으면 영역 없음. 회고·주제는 항상 영역 없음.
- **목표도 영역 색**을 쓴다(영역 기준에서는 "색 = 영역" 하나로). 목표는 모양(●·◯·링)으로 남는다. 영역 없는 인생 목표는 `neutral`.
- `i`번째 영역(`sort_order`, `id` 오름차순) 색 = `AREA[i % 12]`. 색상각·순서는 우주 보기 `GALAXY`와 같고(같은 영역이 두 보기에서 같은 이름의 색), **명도만** 기본 그래프 바탕에 맞게 다시 정했다(우주 값은 어두운 우주 바탕 + 발광 기준이라 흰 바탕에서 대비가 모자라고, 다크 `#141416`에서는 너무 밝다).
- 분기 목표 안쪽 채움은 영역 기준에서 `canvasBg`(`goalSoft`는 종류 기준 전용).

### 1.4 필터 칩 아이콘 = 범례

- 종류 기준: 칩 모양 아이콘(10×10)을 **1.2 종류 색**으로(다크는 다크 값). 칩이 종류 범례다. 꺼진 칩은 지금처럼 아이콘 opacity 0.35.
- 영역 기준: 칩 아이콘을 `label` 색(무채색)으로 — 색이 종류를 뜻하지 않는다는 표시. 범례는 위 영역 범례가 맡는다.
- 노드 검색 결과·미리보기 연결 목록의 모양 아이콘도 같은 규칙(현재 색 기준의 노드 색).

### 1.5 선 색

**출발 노드(`edge.source`) 색 + 낮은 투명도**로 정한다(양 끝 섞기 대신 — 섞으면 빨강+청록처럼 반대색끼리 탁한 회색이 나오고, 선마다 계산이 하나 더 든다). `belongs`는 자식 → 부모 방향이라 **자식 색**, `topic`은 항목 → 주제라 **항목 색**이 된다.

| 종류 (`edge.kind`) | 모양 | 굵기 (s) | 알파 라이트 / 다크 |
|---|---|---|---|
| 소속 `belongs` | 실선 | 1.5 | 0.55 / 0.45 |
| 연결 `link` | 실선 | 1 | 0.42 / 0.34 |
| 본문 링크 `body` | 실선 | 1 | 0.42 / 0.34 |
| 주제 `topic` | 점선 `[2, 3]`s | 1 | 0.42 / 0.34 |

- 라이트 값을 다크보다 높게 둔 이유: 색 선은 흰 바탕에서 같은 알파라도 더 옅다. 0.30이면 가장 밝은 색(주제·생각·논문)의 선이 바탕 대비 1.36까지 떨어져 예전 무채색 선(`edge` 0.22, 약 1.6)보다 흐렸다. 0.42면 최저 1.56으로 예전과 비슷하다. 다크 0.34는 최저 1.7(회고).
- 노드 1500개 초과: 소속 1s·0.35, 나머지 0.75s·0.14.
- 3절의 굵기·모양 규칙은 그대로(이 표가 3절 표의 색·알파를 대신한다).

**hover·선택 강조**(4절 값을 바꿈):

| 대상 | 노드 알파 | 선 |
|---|---|---|
| H(hover·선택) | 1, 무채색 링(`labelStrong` 2s, 3s 바깥) | H에 붙은 선: 출발 노드 색, 소속 **0.90**, 그 외 **0.70**, 굵기 +0.5s |
| N(이웃) | 1 — **색 그대로** | — |
| R(나머지) | 라이트 0.12 / 다크 0.18 | 0.04 |

- 라벨: H `labelStrong` 500, N `label`, R 숨김(4절 그대로). 색 선이 진해져도 라벨은 바탕색 테두리 3s로 덮고 그 위에 그리므로 대비 5.3 / 6.8 유지.

### 1.6 장식 금지

- 노드에 그라데이션·그림자·발광(`shadowBlur`) 없음. 테두리는 2.1의 고리·빈 모양만(채운 노드에 따로 테두리를 두르지 않는다).
- 바탕은 단색 `canvasBg`. 영역 기준에서도 성운·안개를 그리지 않는다(그건 우주 보기의 몫).

| 회고 | ▪ 작은 정사각형 | 채움 `C`, 모서리 1g | 3.5 고정 |
| 주제(태그) | ◇ 빈 마름모 | 채움 `canvasBg`, 테두리 `C` 1.25s | 3.5 고정 |
| 할 일 (미완료) | □ 빈 정사각형 | 채움 `canvasBg`, 테두리 `C` 1.25s, 모서리 0.75g | 3 고정 |
| 할 일 (완료) | ■ 채운 정사각형 | 채움 `C`, 알파 0.45, 모서리 0.75g | 3 고정 |

- `C` = 노드 색: 색 기준이 종류면 1.2 종류 색, 영역이면 1.3 영역 색. 모양은 두 기준 모두 같다.

모양 크기를 반지름 `r`로 맞추는 법(눈에 보이는 면적을 비슷하게):
- 정사각형 한 변 `1.75r`, 마름모 중심→꼭짓점 `1.3r`, 삼각형 외접원 반지름 `1.3r`(중심을 무게중심에 둠).

### 2.2 크기 (연결 수)

```
r = min(base + 1.2 × √degree, 16)      // degree = 현재 보이는 선 기준 연결 수
```
- 회고·주제는 `degree`와 상관없이 3.5 고정.
- 노드 1500개 초과면 `base`를 모두 −1(최소 3).

### 2.3 상태

| 상태 | 표시 |
|---|---|
| 보관(`archived`, "보관 보기" 켰을 때만 보임) | 노드 알파 0.45, 라벨 뒤에 ` · 보관` |
| hover | 4절 강조 규칙 + 커서 `pointer` |
| 키보드 포커스 | `labelStrong` 링 2s(1.1), 노드 가장자리에서 3s 바깥, 라벨 항상 |
| 선택(미리보기 열림) | 포커스 링과 같은 링 + 4절 강조를 hover 없이도 유지 |
| 검색 결과로 이동한 노드 | 선택과 같음 |

- 클릭·hover 판정 영역(`nodePointerAreaPaint`): 반지름 `max(r + 2, 10 / globalScale)` — 화면에서 최소 20×20px.

## 3. 선

> 색·알파는 **1.5절**이 이 표를 대신한다(출발 노드 색). 아래 표는 모양·굵기 기준으로만 본다.

| 종류 (`edge.kind`) | 모양 | 굵기 (s) | 투명도 라이트 / 다크 |
|---|---|---|---|
| 소속 `belongs` | 실선 | 1.5 | 0.50 / 0.45 |
| 연결 `link` | 실선 | 1 | 0.22 / 0.22 |
| 본문 링크 `body` | 실선 (연결과 같게) | 1 | 0.22 / 0.22 |
| 주제 `topic` | 점선 `[2, 3]`s | 1 | 0.22 / 0.22 |

- 색은 1.5절(출발 노드 색 + 알파). 화살표 없음(방향은 PARA 배치가 대신 보여 준다).
- 같은 두 노드 사이에 `link`와 `body`가 겹치면 한 줄만 그린다.
- 끝점은 노드 중심, 노드를 선 위에 그린다(선 먼저, 노드 나중).
- 노드 1500개 초과: 소속 1s·0.40, 나머지 0.75s·0.14.

## 4. hover·선택 강조

hover한(또는 선택한) 노드 **H**, H와 선으로 이어진 이웃 **N**, 나머지 **R**. 선 색·알파는 1.5절 표가 우선(N은 색을 그대로 살리고 R만 흐린다).

| 대상 | 노드 알파 | 라벨 |
|---|---|---|
| H | 1 | 항상, `labelStrong`, 굵기 500 |
| N | 1 | 항상, `label` |
| R | 라이트 0.12 / 다크 0.18 | 숨김 |

| 선 | 알파 | 굵기 |
|---|---|---|
| H에 붙은 선 | 소속 0.90, 그 외 0.70 (출발 노드 색) | 표 3 굵기 + 0.5s |
| 나머지 선 | 0.04 | 그대로 |

- 전환: 120ms 선형으로 알파 보간. `prefers-reduced-motion: reduce`이면 즉시.
- 선택 중에 다른 노드에 hover하면 hover가 잠시 우선, 손을 떼면 선택 강조로 돌아간다.
- 빈 곳 클릭·`Esc`: 선택 해제(강조 해제, 미리보기 닫힘).

## 5. 라벨

- 글자: 화면 12px 고정(`12 / globalScale`), 기본 굵기 400, 목표·영역 500. 캔버스 font는 `getComputedStyle(document.body).fontFamily`를 그대로 쓴다(Inter + Pretendard).
- 위치: 노드 아래 가운데, 노드 가장자리에서 3s 아래, `textBaseline = "top"`.
- 가독성 테두리: 같은 글자를 `canvasBg` 색 `lineWidth 3s`로 먼저 stroke, 그 위에 fill.
- 길이: 18자 넘으면 17자 + `…`. hover·선택·포커스 중에는 40자까지.

**확대 배율별 표시 (`k = globalScale`)**

| 종류 | 기본 (노드 ≤ 300) | 노드 > 300 |
|---|---|---|
| 인생·연 목표, 영역 | k ≥ 0.8 | k ≥ 1.3 |
| 분기 목표, 프로젝트 | k ≥ 1.3 | k ≥ 1.8 |
| 논문·세미나·생각·회고·주제 | k ≥ 2.0 | k ≥ 2.5 |
| hover·이웃·선택·포커스·검색 결과 | 항상 | 항상 |

- 노드 > 300이면 라벨 겹침 정리: 우선순위(선택 > hover > 이웃 > 목표 > 영역 > 프로젝트 > 나머지) 순으로 그리고, 이미 그린 라벨 상자와 겹치면 건너뛴다.
- 주제 라벨은 앞에 `#`.

### 6.1 상단 바 (높이 48px, `px-5`, 아래 `border-b border-border`)

- 왼쪽: `h1` "그래프" `text-base font-semibold tracking-tight`, 옆에 `text-xs text-muted tabular-nums` "노드 128 · 선 214" (`ml-3`).
- 오른쪽(`gap-2`): 보기 전환(6.4) → `Button variant="ghost" size="sm"` "배치 초기화"(자유 배치일 때만 보임, 누르면 확인 `Dialog` "끌어 놓은 위치를 모두 지울까요?") → `buttonClass("ghost","sm")` 링크 "목표 지도로 보기"(`/goals` 목표 지도 탭; 그래프를 글로 보는 대안 경로).

### 6.2 필터 바 (높이 44px, `px-5`, `gap-3`, 아래 `border-b border-border`, 바탕 `bg-bg`)

순서대로, 묶음 사이에 세로 구분선 `h-4 w-px bg-border`.

0. **색 기준** `[종류 | 영역]` — 1.3절.
1. **종류 칩** — 토글 버튼, `aria-pressed`. 그룹 `role="group" aria-label="종류"`.
   - 크기 `h-7 px-2 rounded-md text-[13px] gap-1.5 border`.
   - 켬: `border-border-strong bg-subtle text-fg`. 끔: `border-border bg-transparent text-muted`, 모양 아이콘 opacity 0.35.
   - 왼쪽에 노드 모양 아이콘 10×10 SVG(2.1과 같은 모양, 색은 1.4절 — 종류 기준이면 종류 색, 영역 기준이면 `label`). 칩이 범례 역할도 한다.
   - 순서와 기본값: 목표✔ 영역✔ 프로젝트✔ 논문✔ 세미나✔ 생각✔ │ 회고☐ 주제☐ 할 일☐.
2. **영역**, **주제** 선택 — `<select class="rb-select h-7 rounded-md border border-border bg-bg pl-2 pr-7 text-[13px]">`, 앞에 `text-[13px] text-muted` 라벨(`<label>`로 연결). 기본 "전체". 주제 선택은 주제 칩과 별개(선택한 주제와 이어진 항목만 보이기).
3. **체크박스** — "보관 보기", "연결 없는 항목만". 네이티브 체크박스(전역 `accent-color`) + `text-[13px] text-fg`, `gap-1.5`.
4. 필터가 기본값과 다르면 맨 끝에 `ghost sm` "필터 초기화".

- 필터 상태는 URL 쿼리(`?types=&area=&tag=&archived=&orphans=&view=para&color=area`)에 반영 — 새로고침·공유 시 유지.
- 메인 영역 폭 < 900px: 필터 바 대신 상단 바에 `secondary sm` "필터 3"(켜진 조건 수) 버튼, 누르면 아래로 펼친 패널(같은 내용 세로 배치, `p-4 gap-3`).

### 6.3 캔버스 위 요소

- **검색 힌트**(왼쪽 아래 16px): `text-xs text-muted` "노드 검색" + `<Kbd>/</Kbd>`. 클릭해도 검색 열림.
- **확대 버튼**(오른쪽 아래 16px): 세로 묶음 `rounded-lg border border-border bg-bg shadow-sm`, 버튼 각 32×32 `ghost icon`, 사이 `border-t`. 확대(`+`), 축소(`−`), 화면에 맞춤(⤢). 각 `aria-label` "확대"·"축소"·"화면에 맞춤". 미리보기가 열려 있으면 `right: 16 + 320 + 16 = 352px`로 옮긴다.
- **노드 검색 팝오버**(`/`): 캔버스 위쪽 가운데, 위에서 16px, 폭 400px, `rounded-lg border border-border bg-bg shadow-overlay`. 입력 `h-10 px-3 text-sm` placeholder "노드 검색…", 결과 최대 8개 `h-9 px-3` 행: 모양 아이콘 + 제목(truncate) + 오른쪽 `text-xs text-muted` 종류. `role="combobox"`/`listbox`, ↑↓ 이동, Enter → 그 노드로 `centerAt`(400ms) + `zoom(2, 400ms)` + 선택, Esc 닫기. 결과 없음 "일치하는 항목이 없습니다".

### 6.4 미리보기 패널 (노드 선택 시)

- 캔버스 위 오른쪽 오버레이: `top 16, right 16, bottom 16`(내용이 짧으면 높이 auto, 최대 `calc(100% - 32px)` 스크롤), 폭 **320px**.
- `rounded-lg border border-border bg-bg shadow-overlay p-5 flex flex-col gap-4`. `role="dialog"`가 아니라 `role="region" aria-label="미리보기: {제목}"`(포커스를 가두지 않음).
- 열릴 때 캔버스를 줄이지 않는다. 대신 선택 노드가 패널에 가리면 `centerAt`으로 노드를 (캔버스 폭 − 336)/2 지점으로 옮긴다(300ms).

내용(위에서 아래):
1. 머리줄: `Badge`(종류 톤; 목표는 "인생 목표/연 목표 2027/분기 목표 2027-Q1") + 보관이면 회색 배지 "보관" + 오른쪽 닫기 `ghost icon` 28×28 `aria-label="미리보기 닫기"`.
2. 제목: `text-lg font-semibold tracking-tight`, 3줄 넘으면 `line-clamp-3`.
3. 속성 2~3줄: `text-[13px]`, 라벨 `text-muted w-16`, 값 `text-fg`. 종류별 — 프로젝트: 단계/상태·목표·마감일 / 논문: 저자·연도·읽기 상태 / 세미나: 날짜·연사 / 생각: 종류·발전 정도 / 목표: 진행률(%)·영역 / 영역: 프로젝트 수 / 회고: 기간.
4. 요약: `text-[13px] text-muted line-clamp-4` — 한 줄 요약 / 연구 질문 / 핵심 한 줄 / 다음 할 일 / 본문 첫 문단(160자). 없으면 생략.
5. "연결 n" 소제목 `text-xs font-medium text-muted` + 최대 6개 목록(`h-8` 행, 모양 아이콘 + 제목 truncate). 클릭하면 그 노드를 선택(이동 아님). 6개 넘으면 "+ n개 더" `text-xs text-muted`.
6. 바닥: `Button variant="primary" size="sm"` "열기"(상세로 이동). 패널 안 탭 순서는 닫기 → 연결 목록 → 열기.

## 7. 보기 전환 `[자유 배치 | PARA 배치]`

- 세그먼트 컨트롤: 바깥 `inline-flex h-8 rounded-lg border border-border bg-surface p-0.5`, 각 버튼 `h-7 px-3 rounded-md text-[13px]`. 선택: `bg-bg text-fg font-medium shadow-sm`, 비선택: `text-muted hover:text-fg`. `role="radiogroup" aria-label="배치"`, 버튼 `role="radio" aria-checked`, ←/→로 이동·선택.
- 전환 시 시뮬레이션 재가열(`alpha 0.6`) → 노드가 새 자리로 움직이며 약 600ms 정착. reduced motion이면 `warmupTicks 120` 후 바로 정지 상태로 그린다.

### 7.1 자유 배치

- d3-force 기본 + `charge −60`, `link distance` 소속 40 / 그 외 60, `collide r + 4`.
- 끌어 놓은 노드는 `fx/fy` 고정, 놓을 때 `PUT /api/graph/layout`(300ms 디바운스로 묶어 보냄).

### 7.2 PARA 배치

- 열(x 중심, g): 목표 `0` → 영역 `280` → 프로젝트 `560` → 자료(논문·세미나) `840` → 생각 `1120` → 회고 `1400`(켰을 때) → 주제 `1680`(켰을 때). 꺼진 종류의 열은 빼고 왼쪽으로 당긴다(간격 280 유지).
- 힘: `forceX(열 중심) strength 1`, `forceY(0) strength 0.04`, `collide r + 6`, `charge −30`. 저장된 `fx/fy`는 PARA에서는 무시(해제)하고 자유 배치로 돌아오면 복원.
- 목표 열 안의 세로 순서: `forceY` 목표값 인생 `−240` / 연 `0` / 분기 `+240` (strength 0.3).
- PARA에서 끌기는 그 순간만 움직이고 **저장하지 않는다**(열 배치가 기준이므로). "배치 초기화" 버튼은 숨김.
- **열 제목**: 캔버스 위 DOM 줄(높이 32px, `bg-bg/90 border-b border-border`), 각 제목은 열 중심의 화면 x(`graph2ScreenCoords`)에 가운데 정렬, 팬·확대 시 따라 움직인다. 글자 `text-xs font-medium text-muted`, 옆에 개수 `text-xs text-muted tabular-nums`(`text-faint`는 대비 2.6:1이라 쓰지 않음). 문구: "목표", "영역", "프로젝트", "자료", "생각", "회고", "주제".
- **열 구분선**: 이웃 열 중심의 중간 x에 세로선, `divider` 색, 1s, 캔버스 높이 전체.

## 8. 로컬 그래프 (상세 화면)

### 8.1 위치·크기

- 상세 화면의 "연결된 항목" 섹션 줄에 붙인다. 래퍼:
  ```
  <div class="grid gap-8 lg:grid-cols-[minmax(0,1fr)_340px]">
    <ConnectedItems …/>
    <LocalGraph item={…}/>
  </div>
  ```
  → 넓은 화면에서는 상세 화면 **오른쪽 아래**(연결 목록 오른쪽), `lg` 미만은 연결 목록 아래 전체 폭.
- 카드: `rounded-lg border border-border bg-bg`. 머리줄 `h-10 px-3 flex items-center gap-2 border-b border-border`, 캔버스 높이 **260px**(`lg` 미만 220px), 폭은 카드 폭.
- 상세 파일은 C 소유가 아니므로 붙이는 줄은 소유자/관리자에게 요청(팀 문서대로).

### 8.2 머리줄과 접힘

- 왼쪽: 접기 버튼(제목 겸용) `<button aria-expanded aria-controls>` — 셰브런 12px(펼침 ▾ / 접힘 ▸) + "로컬 그래프" `text-sm font-medium` + 이웃 수 `text-xs text-muted`.
- 오른쪽(펼침일 때만): 깊이 세그먼트 `[1단계 | 2단계]`(7절 컨트롤의 작은 판, `h-7`, 버튼 `h-6 px-2 text-xs`), 링크 `ghost sm` "전체 그래프" → `/graph?focus=<type>:<id>`.
- 기본 **펼침**. 접힘 상태는 `localStorage` 키 `rb-local-graph`에 `"collapsed"`로 저장(사이드바 `rb-sidebar`와 같은 방식), 모든 상세 화면에 공통 적용. 접히면 머리줄만(`border-b` 없음).

### 8.3 그리기 규칙 (전체 그래프와 다른 점)

- **색: 종류 색(1.2)만** 쓴다. 영역 토글·영역 범례 없음 — 상세 화면에서는 "이 항목 곁에 어떤 종류가 붙어 있나"가 중요하고, 전체 그래프 기본값과 같은 색이라 옮겨 가도 읽는 법이 같다. 선도 1.5절(출발 노드 색·알파) 그대로.
- 중심 노드(현재 항목): 종류 모양·색 그대로, `r = 8` 고정 + `labelStrong` 링 2s(3s 바깥).
- 1단계 이웃: 2절 규칙(크기는 `base + 1`, 최대 10). 2단계 이웃: 알파 0.55, `r = base`.
- 라벨: 노드 ≤ 25개면 모두 항상 표시, 넘으면 중심·1단계·hover만.
- 자유 배치만, 끌어도 저장하지 않음. 휠 확대 끔(페이지 스크롤 우선) — `Ctrl/⌘ + 휠`, 핀치만 확대. 정착 후 `zoomToFit(0, padding 24)`.
- 클릭: 그 항목 상세로 이동. hover 강조는 4절과 같음.

## 9. 빈 상태·로딩·오류

캔버스 영역 가운데에 `EmptyState`(기존 컴포넌트, 최대 폭 360px).

| 상황 | 제목 | 설명 | 동작 |
|---|---|---|---|
| 항목이 하나도 없음 | 아직 그래프에 보일 항목이 없습니다 | 목표·프로젝트·논문·생각을 만들고 서로 연결하면 여기에 지도처럼 그려집니다. | `secondary sm` "목표 세우기" → `/goals` |
| 필터 결과 0 | 조건에 맞는 항목이 없습니다 | 종류나 영역 필터를 바꿔 보세요. | `ghost sm` "필터 초기화" |
| "연결 없는 항목만" 결과 0 | 연결 없는 항목이 없습니다 | 모든 항목이 어딘가에 이어져 있습니다. | `ghost sm` "모든 항목 보기"(이 체크만 끔) |
| 로딩 (300ms 넘을 때만) | — | `Spinner` + `text-[13px] text-muted` "그래프를 그리는 중…" | — |

로컬 그래프 빈 상태: 캔버스 대신 높이 96px, 가운데 `text-[13px] text-muted` "아직 연결된 항목이 없습니다."

## 10. 노드가 많을 때

| 노드 수 | 처리 |
|---|---|
| ≤ 300 | 기본 |
| > 300 | 라벨 기준 상향(5절), 라벨 겹침 정리 |
| > 1500 | 노드 `base −1`, 선 얇게·흐리게(3절), `cooldownTicks 150`, `d3AlphaDecay 0.04`, hover 알파 보간 끔(즉시). 필터 바 아래 안내 줄(높이 32px, `bg-surface text-[13px] text-muted px-5`): "항목이 많습니다. 영역이나 종류로 좁히면 더 잘 보여요." (닫기 가능, 세션 동안 기억) |

- 공통: 시뮬레이션이 멈추면(`onEngineStop`) 다시 그리기만 하고 계산하지 않는다. 처음 로드 때만 `zoomToFit`.

## 11. 접근성

### 11.1 키보드 (캔버스)

캔버스 래퍼: `tabIndex=0`, `role="application"`, `aria-label="그래프. 노드 {n}개. 화살표로 이동, Enter로 미리보기."`, `aria-describedby`로 아래 단축키 도움말(시각적으로 숨김) 연결. 포커스 표시는 래퍼에 `outline 2px accent, outline-offset −2px`(전체 폭이라 안쪽으로).

| 키 | 동작 |
|---|---|
| 처음 포커스 | 선택된 노드가 있으면 그것, 없으면 가장 큰 인생 목표(없으면 연결 수 최다 노드)에 포커스 링 |
| ←↑→↓ | 그 방향(±45°)에서 가장 가까운 노드로 포커스 이동. **연결된 이웃을 먼저** 찾고, 없으면 전체 노드에서 |
| `[` / `]` | 현재 노드의 이웃을 차례로 순회 |
| `Enter` / `Space` | 선택(미리보기 열기). 로컬 그래프에서는 그 항목으로 이동 |
| `⌘/Ctrl + Enter` | 상세로 열기 |
| `Esc` | 검색 → 미리보기 → 선택 순으로 닫기 |
| `/` | 노드 검색 |
| `+` / `−` / `0` | 확대 / 축소 / 화면에 맞춤 |
| `Tab` | 캔버스를 벗어나 다음 요소(미리보기가 열려 있으면 미리보기 패널)로 |

- 포커스 이동 시 노드가 화면 가장자리 64px 안쪽을 벗어나면 `centerAt`(200ms, reduced motion 0).
- `aria-live="polite"` 영역에 읽어 줄 문장: "{종류} {제목}, 연결 {n}개" (예: "프로젝트 연구 X, 연결 5개"). 선택 시 "미리보기 열림".
- 단축키 `G`(전역, 입력 중 아님): `/graph` 열기. 기존 `shortcuts.ts`의 입력창 제외 규칙을 그대로 따른다.

### 11.2 대비·모양

- 노드 색 3:1 이상(1.2·1.3 표, 최저 3.2 / 3.3), 라벨 4.5:1 이상(라벨은 색 없이 `label`). 흐린 노드·라벨·완료 할 일은 비활성 상태라 예외.
- 종류는 **모양**으로도 구분되므로 색각 이상에서도 읽힌다(색각 이상에서 가까워지는 색 쌍은 모양이 다르다, 1.2). 종류 기준은 필터 칩이, 영역 기준은 영역 범례가 범례를 겸한다. 영역은 색만으로 구분하지 않는다(범례·미리보기 영역 이름·영역 필터).
- DOM 글자에 `text-faint`(#a1a1aa, 2.6:1) 쓰지 않는다 — 보조 글자는 `text-muted`.
- 캔버스 안 포커스 링·선택 링은 `labelStrong`(17:1 이상, 어떤 노드 색과도 겹치지 않음). 캔버스 래퍼 outline은 DOM이라 `accent`(라이트 5.5:1, 다크 6.7:1).

### 11.3 모션

- `prefers-reduced-motion: reduce`: 모든 `centerAt`/`zoom` 시간 0, hover 보간 끔, 배치 전환은 미리 계산 후 한 번에 표시(7절).

### 11.4 대체 경로

- 캔버스는 화면 읽기 프로그램에 한계가 있으므로 상단 바 "목표 지도로 보기"(트리)를 항상 둔다. 미리보기 패널은 일반 DOM이라 그대로 읽힌다.

## 12. 구현 체크리스트 (C 자가 점검)

- [ ] 라이트/다크 전환 시 캔버스 색이 즉시 바뀐다(새로고침 없이).
- [ ] 종류 기준에서 9종류가 1.2 표 색으로, 영역 기준에서 1.3 표 색으로 그려진다(목표 포함). 필터 칩 아이콘이 같은 색이다.
- [ ] `color=area`가 URL에 남고 새로고침해도 유지된다. 영역 기준에서 영역 범례가 보이고, 칩 아이콘은 무채색.
- [ ] 선이 출발 노드 색이고, hover 시 이웃 노드 색은 그대로·나머지만 흐려진다. 라벨은 색 없이 테두리로 읽힌다.
- [ ] 선택·포커스 링이 무채색(`labelStrong`)이다.
- [ ] 우주 보기 색은 바뀌지 않았다.
- [ ] 로컬 그래프는 종류 색, 토글 없음.
- [ ] 확대 1배에서 목표·영역 라벨만, 2배에서 모든 라벨.
- [ ] hover 시 이웃 외 노드가 흐려진다(0.12 / 0.18).
- [ ] PARA 배치에서 열 제목이 팬·확대에 따라 움직이고 끄면 사라진다.
- [ ] 키보드만으로 노드 이동 → 미리보기 → 열기까지 된다.
- [ ] 로컬 그래프 접힘이 다른 상세 화면에서도 유지된다.
- [ ] 노드 0개·필터 0개·로딩·오류 상태 문구가 위 표와 같다.
