# 계획: '노트' 자료 종류 (단계 N)

> **승인됨 (2026-11-04)**. 공부한 것을 정리하는 노트 종류만 추가한다. 복습 일정·공부 시간 기록은 만들지 않는다. `src/app/loading.tsx` 금지. 단계 K 병합 뒤 시작.

## 1. 데이터 (마이그레이션 `0007`, CREATE TABLE만)

새 `notes`

| 열 | 비고 |
|---|---|
| `id`, `title`(not null), `body`(Markdown, 기본 "") | |
| `source_kind` | `book`(책)·`lecture`(강의)·`video`(영상)·`article`(글)·`other`(기타), null 허용 |
| `source_title`, `source_url` | 선택. URL은 http(s)만 |
| `area_id` | → areas, on delete set null (영역 소속; 프로젝트는 기존 다대다 연결로) |
| `archived_at`, `created_at`, `updated_at` | |

- `ITEM_TYPE`에 `note`(라벨 "노트"), `ITEM_ROUTE` `/notes`. 태그·연결·위키링크·보관·삭제 정리는 기존 공용 경로(`item_tags`, `links`, `removeLinksFor`)를 그대로 탄다.
- 루트 DB에는 적용하지 않는다. 병합 후 "루트 DB `npm run db:migrate` 필요"로 보고.

## 2. 연결할 곳 (논문·세미나·생각과 같은 수준)

| 곳 | 내용 |
|---|---|
| 화면 | `/notes` 목록(기존 list 컴포넌트: 표/카드·정렬·주제·출처 종류 필터), `/notes/new`, `/notes/[id]`(공용 상세 부품·MarkdownEditor 그대로·자동 저장·연결된 항목·로컬 그래프·보관) |
| 사이드바 | "자료" 구역의 논문 다음에 "노트" |
| `/resources` 주제 화면, 영역 상세 자료 목록 | 노트 포함 |
| Cmd+K 검색 | 노트 소스(제목·본문·출처 이름) |
| 그래프·우주 보기 | 노드 종류 `note` + 종류 색 하나(`docs/design/graph.md` 팔레트·대비 규칙), 우주 보기 점수 직접 값 |
| 위키링크 | `[[제목]]` 대상 |
| 보관함, 주제 화면, 주간 회고 초안 "이번 주 만든 항목" | 노트 포함 |
| N 단축키·빠른 캡처 | `/notes`에서 N → 새 노트, 빠른 캡처에 "노트" 종류(제목+본문 → 새 노트) |
| seed | 가짜 노트 2개(책 1·강의 1) |

검색 팔레트 "타입별 배지 색이 모두 다름" 테스트를 지키도록 배지 톤을 고른다(남은 톤 확인).
