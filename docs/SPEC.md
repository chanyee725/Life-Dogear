# Research Brain — 명세 (사용자 원문 + 확정 사항)

## 확정 사항 (2026-11-02, 원문보다 우선)
- DB: Turso(libSQL) + Drizzle. `@libsql/client` 사용. `DATABASE_URL`이 없으면 로컬 파일 `file:./data/local.db`, 있으면 Turso(`DATABASE_URL`, `DATABASE_AUTH_TOKEN`). 원문의 "외부 서버로 데이터 보내지 않기"는 DB에 한해 사용자가 Turso로 바꿈. 토큰 값은 사용자가 .env에 직접 넣음 — 세션은 .env를 읽거나 만들지 말고 .env.example만 작성.
- PDF 파일: 로컬 `data/pdfs/`에 저장 (클라우드 업로드 없음).
- 실제 데이터는 사용자가 나중에 올림. 샘플 데이터는 seed 스크립트로만.
- git 커밋은 이 저장소 local config 사용자(chanyee725)로. 커밋 메시지 `feat(scope): ...` / `fix(scope): ...` 영어.

## 목표
논문, 세미나 노트, 내 생각, 내 연구 프로젝트를 한곳에서 관리하는 개인용 웹앱. 노션에서 옮기는 것이라 "깔끔하고 조용한 디자인"과 "PDF 이어 읽기"가 핵심. 혼자 쓰는 앱, 로컬 실행.

## 기술 스택
- Next.js (App Router) + TypeScript + Tailwind CSS
- DB: (확정 사항 참고 — Turso/libSQL + Drizzle ORM)
- PDF 뷰어: pdf.js (react-pdf 등)
- 에디터: 마크다운 지원 블록 에디터 (Tiptap 또는 BlockNote)

## 데이터 모델 (4개 + 연결)
1. 연구(Project): 제목, 연구 질문, 단계(주제 탐색→주제 확정→제안서 작성→문헌 검토→데이터 수집→초안 작성→수정·교정→제출 완료), 시작일, 마감일, 태그, 본문
2. 논문(Paper): 제목, 저자, 연도, 학술지·학회, DOI/링크, PDF 파일, 읽기 상태(읽을 예정/읽는 중/다 읽음), 중요도(핵심/참고/가볍게), 태그, 한 줄 요약, 마지막 읽은 페이지, 마지막 읽은 시각, 본문
3. 세미나(Seminar): 제목, 날짜, 연사, 주최·장소, 종류(세미나/학회 발표/강의/웨비나/기타), 핵심 한 줄, 자료 링크, 태그, 본문
4. 생각(Thought): 제목, 종류(아이디어/질문/비판·반론/연결 발견/메모), 발전 정도(씨앗/자라는 중/정리됨), 태그, 본문
- 연결: 모든 항목끼리 다대다 연결 (논문↔연구, 세미나↔논문, 생각↔논문/세미나/연구 등)
- 하이라이트(Highlight): 논문 id, 페이지 번호, 선택한 텍스트, 색상, 내 메모, 생성 시각
- 태그는 4개 타입이 공유

## 핵심 기능
### 1. PDF 이어 읽기 (가장 중요)
- 논문에 PDF 업로드 → 앱 안 뷰어로 열기
- 스크롤할 때마다 현재 페이지와 스크롤 위치 자동 저장 (디바운스)
- 다시 열면 마지막 위치로 바로 이동
- 홈 "이어 읽기" 섹션: 읽는 중인 논문을 최근 순으로, 진행률(현재 페이지/전체 페이지) 바
### 2. 하이라이트와 메모
- PDF 텍스트 드래그 → 하이라이트 + 메모 저장
- 논문 상세 옆 패널에 하이라이트 목록, 클릭하면 해당 페이지로 이동
- 하이라이트에서 "생각 만들기" → 해당 논문과 연결된 생각 생성
### 3. 양식 (템플릿)
- 새 논문: 왜 읽나 / 핵심 내용(연구 질문·주장·기여) / 방법론 / 주요 결과 / 한계 / 인용할 부분 / 내 생각 / 라이너 스콜라 메모
- 새 세미나: 현장 메모 / 핵심 3가지 / 인상 깊은 점 / 남은 질문 / 언급된 논문 / 내 연구에 적용할 것
- 새 연구: 진행 체크리스트, 후보 주제 비교표, 초록~참고문헌 초안 구조, 피드백 기록
### 4. 홈 대시보드
- 이어 읽기 / 진행 중인 연구(단계별 칸반) / 최근 생각 / 최근 세미나
- 상단 빠른 입력창: 엔터 → 생각으로 저장
### 5. 검색과 연결 보기
- 전체 검색 (Cmd+K 커맨드 팔레트): 제목, 본문, 하이라이트
- 상세 페이지 하단 "연결된 항목"과 "이 항목을 참조하는 곳(백링크)"
- 태그별 모아보기
- (3단계) 연결 관계 그래프 뷰
### 6. 논문 추가 편의
- DOI나 arXiv 링크 → 제목·저자·연도 자동 채우기 (Crossref, arXiv 공개 API)
### 7. 라이너 스콜라 연동
- 라이너가 공식 API나 내보내기 기능을 제공하는지 먼저 확인. 추측 금지, 확인 안 되면 그렇다고 보고.
- API가 없으면: 라이너에서 복사한 답변·요약·하이라이트를 붙여넣으면 논문의 "라이너 메모" 섹션에 출처와 날짜를 붙여 저장.
- 논문 상세에 "라이너에서 열기" 버튼 (논문 제목 검색 링크)

## 디자인 가이드
- 조용하고 미니멀. 참고: Linear, Things, Craft, Reflect
- 넉넉한 여백, 얇은 구분선, 그림자 최소화, 둥근 모서리 8px
- 폰트: Pretendard(한글) + Inter(영문/숫자)
- 무채색 위주 + 포인트 색 하나. 상태·종류만 은은한 색 배지
- 라이트/다크 모드
- 왼쪽 사이드바(홈/연구/논문/세미나/생각/태그) + 본문
- 목록은 표 보기 / 카드 보기 전환
- 단축키: Cmd+K 검색, N 새 항목, / 빠른 입력
- UI 문구는 전부 한국어

## 진행 방식
1. 먼저 전체 계획(폴더 구조, 스키마, 화면 목록)을 사용자에게 보여주고 확인받은 뒤 시작.
2. 1단계 MVP: 데이터 모델, 4개 타입 CRUD, 연결, 양식, 홈 대시보드, PDF 뷰어 + 이어 읽기
3. 2단계: 하이라이트, 검색, DOI 자동 채우기, 라이너 메모
4. 3단계: 그래프 뷰, 데이터 내보내기(JSON/Markdown), 백업
- 각 단계가 끝나면 실행 방법과 확인할 것을 알려주고 멈춤.
- 샘플 데이터 몇 개로 화면 확인 가능하게.
